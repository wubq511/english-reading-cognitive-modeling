# Research Audits

`reports/research/` contains scoped, primary-source audits that update or constrain the canonical synthesis. These are durable research assets, not raw search notes.

- [Phase 0 item/data source audit](phase-0-item-data-source-audit.md): CSE/PELDiaG/TSC/J. Intell. lineage, item assets, external process datasets, rights and exact acquisition queue.
- [Methods and governance source audit](methods-and-governance-source-audit.md): all 25 external sources used by the AI and human-research protocols, including version-specific PDF rights gates.
- [Existing literature validation audit](existing-literature-validation-audit.md): local-PDF recheck of seven high-leverage A/A+/B/C/D/E/UIB claims and transfer boundaries.
- [Public repository source distribution audit](public-repository-source-distribution-audit.md): capacity, rights and fail-closed collaborator/Agent acquisition design.
- [Agent first-entry bootstrap audit](agent-first-entry-bootstrap-audit.md): Codex/Claude rule-loading and SessionStart Hook trade-off; records why root instructions are the current startup mechanism.

An audit may narrow a prior claim but does not silently replace `reports/project_state/` or `reports/synthesis/`. When an audit changes current status, update the relevant canonical state/synthesis file and the conflict or claim ledger in the same change.
