## 研究概览

- **研究问题**（物理页 2、打印 19–20）：RQ1 普适提供的住宿（universally offered accommodations）的可及性与有用性；RQ2 住宿对分数信度的影响；RQ3 住宿对推断效度的影响。
- **样本**: 131 名 12 年级学生，美国新泽西州 3 所高中（1 所公立、2 所私立宗教女校）；75% 女性（98/131），民族多样（表 1，物理页 4）。依 ORF CBM（Bader 阅读清单三段取中位数）分组：SWOFI（无功能损伤）n = 83、SWFI（有功能损伤）n = 44；4 名 CBM 分数落在 150–160 间隙的学生被排除（物理页 5）。分组用功能损伤（access skill 缺陷）而非残疾类别。
- **设计**: 随机/对照实验。学生在组内随机分配条件，形式（A/B）与条件（NA/ACC）顺序 counterbalanced（物理页 5）；两形式、两条件内完成同一套 NAEP 题组。无干预对照组之外的额外组；住宿是自愿访问式（点击按钮激活）。
- **任务与材料**（物理页 4–5）:
  - 计算机化阅读理解测试：取自 NAEP 12 年级公开题库，每形式 2 篇短文 + 26 道多项选择（constructed-response 题改写为 MC）；保留 NAEP 25 分钟时限，作者明确设计为非 speeded（物理页 3）。
  - 住宿包：计算机化音频朗读（passages 与 questions 均可）+ 时限耗尽后 50% 额外时间。程序记录住宿被访问的次数（点击计数）。
  - 其他测量：TAMI-ARM 可及性专家评级（4 名博士研究生）、评价调查（定性与定量）、人口学问卷。
- **变量**:
  - 产品分数：NA 分、ACC 分、boost（ACC−NA）及组间 boost 差（物理页 6–7）。
  - 过程指标：住宿访问次数（点击次数）、测试用时（Time–NA / Time–ACC，表 2）。
  - 缺失指标：全数据缺失率（<7%）、多重插补（25 次）。
  - 外部锚：ORF CBM（分组用）、TAMI-ARM 评级（可及性）。

## 核心发现（按四类主张）

### Class 1：可用性 / 偏好

1. **专家可及性评级中上**：TAMI-ARM 对 52 项（每形式 26 项）评级，61% 为 3–4 级（"Maximally Accessible for Nearly All/Most Test-Takers"），38% 为 2 级，0 项为 1 级；总体均值 2.8，作者认为与 Beddow et al. (2013) 州评估回顾相当（物理页 6、8）。引文："For 52 items, 61% were coded 3 or 4 … Another 38% of the ratings were coded 2 … and no items were coded 1"（物理页 6）。
2. **学生主观满意度高但分布不均**：98% 认为测试呈现组织有序，94% 认为测试格式易用；组件好评率 time remaining 82%、passage 与 question 并排 91%、training 67%（物理页 6–7）。但住宿有用性评价明显走弱：仅 53% 认为音频朗读有帮助、61% 认为额外时间有帮助（物理页 7）。
3. **定性反馈与定量评分并存**：18 名学生留言称测试"easy"（与成绩无关；作者提示"easy"可能仅指"符合日常测试经验"，物理页 6）；31 名学生负面评论音频技术质量——"The audio was read to me in a monotone computerized voice, and it sounded staticky and harsh on the ears"（物理页 6）；15 名学生称额外时间"心理上有帮助"但**无人实际使用**该住宿（物理页 6）。
4. **感知—使用分离**：多数学生对住宿反馈正面，但实际使用量很低（样本 M = 3.01 次），许多学生自述"不需要住宿"（物理页 7–8）。作者据此提出未来研究假设之一：学生对测试表现及住宿影响的自我评价可能是差劲的（物理页 8–9）。这与文中引用的 Roach et al. (2010) 一致（感知与分数影响不必然匹配，物理页 2）。

### Class 2：行为改变

1. **住宿访问量随功能损伤增加**：SWFI 平均访问住宿 3.01 次 vs SWOFI 2.38 次，t(55) = −2.62, p < .05，d = −0.17（小效应）（物理页 6）。住宿使用（点击激活次数）被程序逐次记录，是纯过程指标。
2. **额外时间住宿近乎零使用**：全样本仅 2 名学生使用额外时间；两组平均用时均低于可用时限（物理页 6–7）。作者将之归因于测试被有意设计为时限充足（非 speeded）+ 高可及性（物理页 8）。即：一个 UI 供给项（额外时间）的存在本身不产生可观测行为，其使用率受任务需求与设计调节。
3. **用时差异**：SWOFI 两条件下均显著少于 SWFI（NA d = 0.63、ACC d = 0.52；t(117) = −3.28、t(117) = −2.75，均 p < .05）（物理页 6）。
4. **住宿使用与分数变化关系不显著**：boost 与住宿访问量相关 r = .143, p = .06（边缘，作者指出因无 boost 且使用量低而难以解释）（物理页 7）。
5. **行为指标的方向性意义**：住宿使用在 SWFI 上伴随构念无关方差下降（见 Class 4-3），在 SWOFI 上无此效应——同一行为（点击音频）的测量意义分群而异（物理页 7–8）。

### Class 3：仪器信度与缺失

1. **数据缺失率低且被处理**：缺失值分析显示 <7% 数据缺失，均值比较采用 25 次多重插补（Graham et al. 2007 指南）（物理页 5）。未报告缺失是否按条件/组别分布不均——**本文不提供"UI 变体移动缺失率"的直接证据**。
2. **信度跨条件稳定（SWOFI）/ 极不稳定（SWFI）**：Cronbach's alpha（表 3，物理页 7）：SWOFI 四格（NA-A .85 [.78,.91]、ACC-A .86 [.78,.92]、NA-B .82 [.73,.89]、ACC-B .79 [.68,.87]）跨条件几乎无变化；SWFI 四格（.53 [.14,.79]、.80 [.67,.90]、.75 [.56,.88]、.36 [−.12,.70]）极不稳定。Feldt 检验（Feldt & Kim 2006）在 NA Form A 上发现组间差异、在住宿条件下该差异消失；Form B 相反（NA 无差异、住宿下有差异）（物理页 7）。
3. **SWFI 信度估计不可靠**：作者明示 SWFI 组 alpha 受样本量限制——项目数（26）超过参与者数（18–23），"these analyses were suboptimal"（物理页 9）。因此 SWFI 的 alpha 波动不能解读为可靠的"仪器效应"。
4. **评分者一致性**：TAMI-ARM 52 项中 50 项两评分者一致，2 项由第三人裁决（物理页 6）——可及性评级本身有质量控制。
5. **排除规则**：4 名学生因 CBM 落在组间间隙被排除，属外部测量驱动的样本删减，非 UI 造成的缺失（物理页 5、9）。

### Class 4：学习 / 构念与 estimand

1. **无 differential boost**：SWOFI 与 SWFI 的 boost 差 t(90) = −.782, p = .44，不显著；功率分析显示 n = 44（SWFI）足以检测大效应（物理页 7）。"No significant differential boost was found."
2. **无分数提升**：两组分数均未因住宿显著提高（组内 t = .068、t = −1.05, p > .05），boost 均值两组都接近 0（SWOFI −0.04 [SD 4.09]；SWFI 0.58 [SD 3.46]）（物理页 6–7）。
3. **住宿改变的是构念无关方差结构而非分数**：SWFI 中阅读流畅度（access skill）与阅读理解的相关在 NA 条件下显著（r = .26, p = .048）、在住宿条件下不显著（r = .12, p = .220）；SWOFI 两条件稳定（r = .25; r = .22）（物理页 7）。作者结论："The accommodations lessened the relationship between the access skill and the target skill for the SWFIs, rather than boosting any groups' scores."（物理页 8）。这是本文对审计最重要的贡献：**UI 变体（住宿路径）可以改变被测量（分数与构念外技能的结构关系）而不移动分数分布**。
4. **组间分数差异仍在**：SWOFI 高于 SWFI，NA d = 0.91（大效应）、ACC d = 0.76（中效应）（物理页 6）。
5. **零效应有条件解释**：作者推断高可及性（TAMI 均值 2.8）+ 充足时限（非 speeded）限制了住宿的影响——住宿是"为改善访问而设"，访问障碍本已很低（物理页 8）。即：**UI 变体效应是条件依赖的，可及性/时限/速度是调节变量**。
6. **构念定义决定住宿恰当性**：12 年级 NAEP 目标构念被界定为 critical thinking，reading fluency 是 access skill（物理页 3）；若把 fluency 视为目标构念的一部分，则本类住宿将损害效度（物理页 2）。作者声明结果可能外推到依赖阅读流畅度的内容学科（如历史），但不适用于把阅读本身作目标构念的测试（物理页 3、8）。

## 边界与局限

- **人群**：12 年级、新泽西 3 校（1 公立 + 2 私立宗教女校）、75% 女性；SWFI 仅 44 人，分组为 post hoc 经验划分（cutoff = 均值下 0.5 SD，作者自认"somewhat high"，组内含 CBM 平均范围学生，物理页 9）。无随机的"无住宿对照组"之外的第三方。
- **任务/工具**：NAEP 公开题改写（constructed-response → MC）；25 分钟非 speeded；自建测试平台（与计算机科学家合作开发），音频为"standard computerized voice"（作者为最小化语速诠释而选，但学生大量负面评价，物理页 6、8）。
- **住宿组合**：只测了音频 + 额外时间（组合提供），且额外时间实际仅 2 人使用——**有效观测的住宿几乎只有音频**；"住宿包"内部无法分离。
- **动机**：低 stakes + 有补偿，学生可能未尽力（引 Attali 2016，物理页 9）。
- **作者自声明局限**（物理页 9）：SWFI 样本小且 cutoff 高；SWFI 信度估计 suboptimal（项目数 > 人数）；低 stakes 动机风险；以及三个待验证假设——分数不能完全捕捉测试体验、学生可能是糟糕的自我评估者、住宿影响高度个体化。
- **不可外推**：不能外推到 speeded 测试、把阅读/流畅度视为目标构念的测试、其他年级/地区、其他住宿类型（尤其非组合单独评估）；alpha 的跨条件"稳定"仅在 SWOFI 上成立。

## 对审计的用途

**在审计主文件中的位置**：主文件第 92 行（E4 检索行）把本文列为 queue 对象，第 147 行指认"testing-specific counterpart (universal design for assessment; accommodations evaluated through process data) was located but is gated——see the acquisition queue"；主文件 UIE 表格无直接引用 METHOD-036 的条目（`grep METHOD-036` 无命中）。以下关系为笔记作者建议，供综合者核对后并入。

**对既有 UIE 条目的支持 / 限定**：

- 支持 **UIE-18**（STANDARD-001 fairness/UD 框架）的实证化：本文展示可及性设计改变"测量与被测量关系"（SWFI 的 access-skill 相关 r = .26 → .12 消失，物理页 7），且零分数提升（物理页 6–7）——即 UI 可及性影响解释而非（必然）影响分数，与 UIE-18 的"可及性即 bias 问题"一致。
- 支持 **UIE-19/20** 的"行为意义人群依赖"主线：住宿使用量（3.01 vs 2.38，物理页 6）与同一行为对不同人群的测量意义（SWFI 有效、SWOFI 无效，物理页 7–8）均随人变化。
- 支持并实例化主文件第 175 行已有论述（"an accommodation does not merely assist a subgroup; it moves the process distribution for that subgroup"）：本文直接给出住宿移动子群构念无关方差结构的证据（物理页 7–8），且该移动不影响分数——**过程分布移动与产品分布不动可以并存**。
- 限定 **UIE-27**（METHOD-012 的 mode 移动分数分布 d = .16–.22）：本文是"同任务内 UI 变体不移动分数分布"的反向实例——但限定条件清晰：高可及性 + 非 speeded + 自愿使用。这强化 UIE-01/02（B7）已确立的"效应条件依赖"，并提示审计综合时须把"可及性/时限/速度"列为调节变量维度。
- 对 Class 3 主线（UI 变体移动缺失率/完整性）：本文是 `UNRESOLVED` 方向——缺失率 <7% 且未按条件分层报告（物理页 5），无证据支持也无证据反驳变体移动缺失率；不宜引用本文声称"住宿不影响缺失"。

**建议的新 UIE 条目草稿**（综合者可按需合并/编号）：

1. **UIE 草稿 A（Class 4，`SUPPORTED` within study）**：在同一任务内，普适提供的 UI 住宿路径（音频朗读 + 额外时间）**不移动产品分数分布**（boost：SWOFI −0.04、SWFI 0.58，组间 t(90) = −.782, p = .44；无 differential boost，功率足以检测大效应）也不改变无损伤组的信度（alpha .79–.86），但**移动有损伤子群的构念无关方差结构**（fluency–comprehension r = .26, p = .048 → r = .12, p = .220 不显著）。证据：物理页 6–7。Scope boundary：12 年级、非 speeded、NAEP 公开题 MC、TAMI 2.8 高可及性平台、住宿自愿访问；效应条件依赖（作者解释为可及性 + 时限充足所致，物理页 8）。
2. **UIE 草稿 B（Class 2，`SUPPORTED` within study）**：住宿/可替代交互路径的**使用量是 person-dependent 的过程指标**（SWFI 3.01 次 vs SWOFI 2.38 次，t(55) = −2.62, p < .05, d = −0.17），且其使用率本身受设计调节——额外时间因时限充足全样本仅 2 人使用（物理页 6–8）。含义：过程指标的低使用/缺失可能是供给设计特征而非个体行为差异；推断前须报告"该 UI 供给在样本中的实际使用率"。Scope boundary：同上；住宿访问为按钮点击计数，非连续轨迹。
3. **UIE 草稿 C（Class 1，`SUPPORTED` within study）**：学生主观评价（98% 认为格式易用；53% 认为音频有帮助）与实际使用（M = 3.01 次）及分数影响**三方分离**——偏好/满意度证据不能推出行为或测量效应（物理页 6–8）。Scope boundary：低 stakes、补偿参与、自建平台；作者自列"学生可能是糟糕的自我评估者"为待验证假设（物理页 8–9）。
