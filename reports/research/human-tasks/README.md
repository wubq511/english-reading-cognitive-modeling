# 人工事项登记册（human-tasks）

本目录登记只有研究成员本人能做的事：环境配置、需权限数据库检索、付费墙/登录获取。登记由 `ercm-research` 负责，执行由用户完成。本目录文件一律用中文写；文献条目的标题、作者、出处保持原文，方便直接检索下载。

## 规则

- Agent 在任何一步产生人工事项时立即登记到对应文件，并在聊天里点名「哪个文件、哪一节」；人工事项不得埋在长报告正文里。
- 一票一文件：每个 decision ticket / 研究问题一个文件，文件名带票号与可读 slug（如 `wayfinder-5-ui-instrument-effects.md`）。跨票的常设环境配置在 [setup.md](setup.md)。
- 每条事项写清：要拿什么/配什么、为什么需要、渠道或精确检索式、直接可点的链接。
- 完成项不删除：勾选并标注完成日期与落点（如 `sources/` 里的 source ID）。本目录是 append-and-resolve，不静默重写。
- 密钥、密码、身份映射不进本目录；密钥一律走环境变量。
