## 0. 先行结论（Executive Findings）

1. **A 组 5 篇论文分属两个不同的范式**，必须分开看待：
   - **测量模型（measurement model）类**：A1（MSRM）、A3（Mix1P-SR）、A4（SR）、A5（CTDC）。它们的共同点是：把"动作选择"当成观测，通过一个概率模型把**学生级连续潜在能力**直接连到动作上。这一类是真正意义上"process data → ability"的模型。
   - **模式发现（pattern discovery）类**：A2（HMM + 网络分析）。它只估计**隐藏行为/反应状态**，不估计任何学生能力，能力/表现只作为"正确组 vs 错误组"的外部分组变量。
2. **"能力"在这 5 篇论文里几乎都是同一个东西的变体**：*选择预先标注为"正确"的动作的倾向性*。A1/A3/A4/A5 全部要求事先给出每个状态下每个可达动作的"正确/错误"（或"有效/无效"）标注（A1 的 I⁺ 矩阵、A3/A4 的 Iss′、A5 的 Vj(Ft)）。**这是 A 组向英语阅读迁移时最根本的约束**：阅读中的 scroll / viewport / underline 没有天然的"正确/错误"。
3. **没有任何一篇论文完成了"raw event → 认知"的全链条**。A2 明确承认隐藏状态只是统计状态，认知解释（Polya 四步）是事后贴标签 [A2, p.5, §2.2]。A1/A4/A5 的"能力"语义上限是"在预定义正确动作上的选择概率"，不构成对阅读认知技能的构念有效性证明。
4. **时间信息只有 A5 真正用了**（连续时间 marked point process + 指数等待时间 + 速度特质 τ）。A1/A3/A4 只用动作顺序；A2 只用动作顺序。A5 的实证里，速度特质在控制能力后只额外解释约 1% 方差（ΔR² = 1.09%，p=0.01）[A5, p.1065-1066, Table 4-5]，说明"时间信息"的价值存在但有限。
5. **行为异质性（same ability, different strategy）只有 A3 从模型内部处理**（离散潜在类别 + 类别专属状态参数）。A2 用正确/错误二分做组间比较（模型外处理）；A1/A4/A5 明确假设学生同质 [A3, p.81, §1]。
6. **多题 / 新题泛化**：A1/A3/A4/A5 在结构上都支持"共享学生能力、跨多个任务"（局部独立假设），**但每个新任务都必须人工重定义状态空间 + 动作正确性标注**。没有任何机制自动泛化到新 passage。
7. **对英语阅读项目最有架构价值的三个组件**：(a) A4/A5 的"动作选择 + 能力"multinomial logit 连接（可迁移到 option elimination / answer 等有正确性的动作）；(b) A1 的多维 I⁺ 设计矩阵思路（Q-matrix 式的"动作×技能"映射，可迁移到阅读技能标注）；(c) A3 的潜在类别（可迁移到"不同阅读策略"的建模）。**而 scroll / viewport / pointer 这类无正确性标注的行为，A 组没有一个模型能直接处理。**

# 1. A1 — MSRM（Han, Ji, Wang, Liu, 2025, Behavior Research Methods 57:152）

## 1.1 研究问题

把 Han et al. (2022) 的**单维** Sequential Response Model（SRM）扩展为**多维** MSRM，使得一个状态转移可以被多个能力维度/技能共同驱动，从而用完整过程数据同时估计"学生在 D 个维度上的能力向量"和"任务的转移倾向参数"。论文明确回答三个问题：(1) SRM 如何理论上扩展为 MSRM 及如何估计；(2) 估计方法在各种条件下的准确性；(3) 如何实证应用，相比传统基于结果(outcome)的评估能提供什么额外信息 [A1, p.3, §Introduction]。相比此前方法（Markov-IRT、MDP-MM、CTDC、SRM、SR 等），**新增能力是"多维能力"**，此前模型都只测单维 problem-solving ability [A1, p.2]。

## 1.2 数据结构

- **一个 observation**：学生 i 在任务中的一条**状态序列** S_i = (S_{i,1}, …, S_{i,T_i})，其中每个 S_{i,t} 是一个**任务状态**（task state），不是 raw event [A1, p.3]。
- **一个 action**：一个状态转移 x_j → x_k，等价于"从当前状态可达集合 M_j 中选下一个状态" [A1, p.3]。
- **action vocabulary（状态数）**：每个任务各自定义。模拟任务 8 个状态（A–G + #），18 种可能转移 [A1, p.6, Table 1]；橄榄油任务 12 状态、33 转移 [A1, p.10]；保温瓶任务 26 状态、179 种观察到的转移 [A1, p.13]。
- **数据形式**：state sequence（有序），**不含时间戳**（论文明确只建模 response steps，不考虑 timing [A1, p.15, §Conclusion]）。
- **是否含 response correctness**：不含结果变量进模型；但**要求每个状态转移与能力维度的关系 + 正确/错误标注**（I⁺ 矩阵）预先给定 [A1, p.4, Eq. 2 下方定义]。
- **task/item ID**：单任务建模；论文的两个实证各自只分析一个任务 [A1, p.9-14]。
- **学生级变量**：无协变量。能力 θ_i ~ MVN(0, Σ)。
- **多个任务**：MSRM 本身支持多任务共享 Σ 的表述，但实证研究各自单任务。橄榄油任务：800 名八年级学生组成 400 对，180 对完成，322 种不同响应模式，序列平均 18.633 次转移（范围 1–81）[A1, p.10]；保温瓶任务：632 名学生，339 种模式，平均序列长 7.337 [A1, p.13]。

**简化示例（橄榄油任务）**：状态 = (两人杯中水量) 如 [0,0]→[3,0]；转移 AB 的 I⁺ = (1,0)（仅 D1 做正确动作）；CA 的 I⁺ = (0,−1)（D2 做错误动作）[A1, p.10, Table 4]。

## 1.3 预处理 / 动作编码

- 核心：**需要领域专家预先完成三件事**：(1) 定义任务的所有状态；(2) 定义每个状态的可达状态集 M_j；(3) 定义每个转移的 I⁺ 向量（涉及哪些能力维度、正确=+1/错误=−1/无关=0）[A1, p.4]。
- 保温瓶实证展示了"人工编码"的操作：用三位编码表示状态（第 1 位：累计测试材料数 0–6；第 2 位：VOTAT 策略应用 0/1；第 3 位：温度设置是否合适 0/1），再按三元规则定义技能关系 [A1, p.13, §Empirical study II]。论文称"一旦状态定义规则建立，可以用程序自动从原始数据提取状态序列" [A1, p.13]——但规则本身是人工的。
- 不做 action aggregation、不丢弃低频 action（作为参数估计频率数据）。
- **模型真正吃进去的是"已被人工高度抽象后的 state sequence + 人工标注的正确性"**，不是 raw process data。这对英语阅读项目是重要警示。

## 1.4 模型变量

| 类型 | 变量 | 说明 |
|---|---|---|
| 可观测 | S_i（状态序列） | 学生 i 在任务中的状态轨迹 |
| 可观测 | R（任务规则） | 状态集、可达集、I⁺ 矩阵（专家预先给定） |
| 潜在 | θ_i = (θ_{i1},…,θ_{iD}) | 多维能力向量，学生级 |
| 潜在 | Σ | 能力维度间的协方差矩阵 |
| 参数 | λ_{j,k} | 状态转移倾向参数（任务级/item 参数），每个可达转移一个，满足 Σ_{k∈M_j} λ_{j,k} = 0 |

## 1.5 模型机制

### 1.5.1 生成过程

> 每个学生有一个 D 维能力向量 θ_i ~ MVN(0, Σ)。学生从初始状态出发，在每一步：当前状态 S_{i,t} = x_j 决定可达的下一状态集合 M_j；对每个可达状态 x_k，模型给一个"转移倾向"分 exp(λ_{j,k} + I⁺_{j,k}·θ_i)，其中 I⁺_{j,k}·θ_i 是该转移在 D 个维度上与 θ_i 的内积（+1 维度的能力越高越倾向选该转移，−1 维度能力越高越不倾向）。所有可达状态的分数归一化即得选择概率（multinomial logit）。学生能力 + 任务参数共同"生成"整条状态序列。

### 1.5.2 数学结构

**SRM（单维基础版，Eq. 1）**：
```
P(S_{i,t+1} = x_k | S_{i,t} = x_j, θ_i, λ, R) = exp(λ_{j,k} + I⁺_{j,k}·θ_i) / Σ_{x_h∈M_j} exp(λ_{j,h} + I⁺_{j,h}·θ_i)
```
[A1, p.3, Eq. 1]

**MSRM（多维版，Eq. 2）**：把标量 θ 换成向量 θ_i，I⁺_{j,k} 换成向量 I⁺_{j,k} = (I⁺_{j,k,1}, …, I⁺_{j,k,D})：
```
P(S_{i,t+1} = x_k | S_{i,t} = x_j, θ_i, λ, R) = exp(λ_{j,k} + (I⁺_{j,k})ᵀ·θ_i) / Σ_{x_h∈M_j} exp(λ_{j,h} + (I⁺_{j,h})ᵀ·θ_i)
```
[A1, p.4, Eq. 2]

其中 I⁺_{j,k,d} ∈ {−1, 0, +1}：转移 x_j→x_k 涉及第 d 维且正确 = +1；不涉及 = 0；涉及且错误 = −1 [A1, p.4, Eq. 2 下方]。

**整条序列概率（Eq. 3）**：
```
P(S_i | λ, θ_i, R) = ∏_{t=1}^{T_i−1} P(S_{i,t+1} | S_{i,t}, θ_i, λ, R)
```
[A1, p.4, Eq. 3]

**贝叶斯后验（Eq. 4）**：`p(Θ, λ | S, R) ∝ p(S|Θ,λ,R) · p(Θ,Σ,λ)`，其中 θ_i ~ MVN(0,Σ)，Σ ~ Inv-Wishart(Σ₀, m) [A1, p.5, Eq. 4]。

- 可识别性约束：每个状态出发的所有转移倾向 λ 之和为 0 [A1, p.4]。
- 论文明确指出：当前加法形式等价于**补偿性 MIRT**（如 M2PL）；也可改用非补偿形式 [A1, p.4]。
- 语义：λ_{j,k} 是"任务内在特性"（该转移的固有倾向，越大越容易被选）；θ 是学生能力；I⁺ 是**专家标注的"这个转移测哪个技能、是正确还是错误"**。因此"能力"的含义 = **在 I⁺ 标注为正确的转移上选择倾向的强度**。

## 1.6 时间建模

- **动作顺序**：考虑（状态序列的顺序就是行为顺序）。
- **真实 timestamp / duration / inter-event time**：均不考虑。论文在 Conclusion 明说"只关注响应步骤，没有考虑响应的时间信息"，并留作未来扩展 [A1, p.15]。
- 模型是 **discrete-time / sequence-only**。

## 1.7 潜在状态

- **MSRM 没有隐藏状态**。它的"状态"是**可观测的任务状态**（专家定义的、系统配置的累计结果），不是潜在变量。唯一的潜在结构是 θ_i（连续能力向量）。
- 状态空间由任务设计/专家定义（确认式，confirmatory），不是数据驱动发现 [A1, p.15, §Conclusion]。

## 1.8 能力 / 潜在特质

- **多维**（D 维能力向量），**student-level**。
- 能力通过 I⁺ 设计矩阵进入 multinomial logit 的**动作选择**概率，影响的是"选正确/错误转移"的倾向。不直接建模"答对/答错"（结果），结果正确性被编码在 I⁺ 标注里。
- 能力维度间协方差 Σ 被估计（贝叶斯），用于刻画维度关系。
- **Process → Ability 链路**：
  `state sequence → [专家标注 R: 状态/可达集/I⁺正确性] → multinomial logit 选择概率 → θ_i（多维能力向量）`
  中间没有额外的 latent state 层；**正确性标注是这条链路成立的前提**。

## 1.9 行为异质性

- **不处理**。所有学生共享同一套 λ，唯一差别是 θ_i。论文没有 mixture/class。策略差异只能体现在不同序列路径上，但模型不提供显式类别。"两个能力相近但策略不同"的学生在模型里是同质的。A3 论文明确把这一点列为 SR 类模型的共同局限 [A3, p.81]。

## 1.10 题目 / 任务效应

- **论文未明确论述多任务联合估计**（两个实证均为单任务）；从模型形式看，θ 分布（MVN(0,Σ)）在结构上可跨任务共享（此为结构推断），但**每个任务的状态空间、可达集、I⁺ 都必须单独定义**。
- item difficulty 由每个转移的 λ 承载（λ 大 = 该转移倾向强，可理解为容易/诱导性强）[A1, p.4]。
- 不同任务的 action space **不必一致**（各自定义）。
- **换一道新英语阅读题**：必须为它重新做专家状态定义 + I⁺ 标注 + 估计 λ；理论上有 θ 的共享尺度（MVN(0,Σ)），新任务 λ 估计后可把它纳入；但**没有自动机制**。论文自己也承认维度结构需先验指定，并指向"数据驱动自动状态编码"作为未来方向（Wang & Liu 2024 处理 10,000 状态规模）[A1, p.15]。

## 1.11 参数估计 / 训练

- **Bayesian MCMC**：Metropolis–Hastings 采样 θ_i 和 λ_{j,k}；Gibbs 采样 Σ（Inv-Wishart 全条件分布）[A1, p.5-6, Eqs. 5-7]。
- 先验：θ_i ~ MVN(0,Σ)，Σ ~ Inv-Wishart(Σ₀, m)，m ≥ D；λ 有信息/无信息先验两种 [A1, p.6-7]。
- 收敛判据 PSRF < 1.1；实证用 2 条链（橄榄油 15,000 迭代、10,000 burn-in [A1, p.11]；保温瓶 20,000 迭代、10,000 burn-in [A1, p.13]）。
- 数据需求（模拟）：n = 500/1000/2000，短/长序列（平均长度约 16–38）[A1, p.7-8, Table 2]。**样本量与序列长度越大估计越准**；先验影响较小。
- **online inference**：论文未实现（实证为离线 MCMC 批处理）。但任务参数（λ、Σ）离线标定后，新学生的 θ 理论上可通过固定参数下的后验更新 / MAP / EAP 近似估计——**"论文未实现"≠"模型结构做不到"**，本报告记为"结构可改造、论文未演示"。
- **新 item 加入**：需重定义状态与 I⁺ 并重估 λ；论文未讨论增量流程。

## 1.12 可识别性 / 假设

- 条件 Markov 假设：下一步选择只依赖当前状态与能力向量 [A1, p.4]。
- 每个状态出发的 λ 和为零（识别约束）。
- 能力多维正态先验、Σ ~ Inv-Wishart。
- **预先指定 I⁺ 矩阵（类似 Q-matrix 的确认式结构）** —— 需要 ground truth。
- 补偿性线性形式（能力可互相补偿）。
- 学生间局部独立。

**在英语阅读交互数据上可能不成立的假设**：(a) 条件 Markov——阅读中"下一步动作"明显受之前读过的内容、正在进行的题目影响，一阶状态不足以捕捉；(b) **I⁺ 标注的语义**——阅读里"滚动到某段"没有"正确/错误"，无法直接给出 I⁺；(c) 单状态到达集有限——阅读界面状态下"可达动作集"难以像 FSA 那样有限且确定。

## 1.13 评估

- **Statistical validity（拟合/恢复）**：模拟参数恢复（RMSE 表，θ RMSE 约 0.32–0.56、λ RMSE 约 0.04–0.10、Σ 相关系数恢复良好，见 [A1, p.8, Table 2]）；PSRF < 1.1；后验预测 p 值（橄榄油 ppp=0.693，保温瓶 ppp=0.178，落在可接受区间）[A1, p.11, p.13]。
- **Predictive validity（预测）**：无预测性验证（无 holdout、无分类/预测任务）。只有"能力估计 × 任务结果"的相关：保温瓶任务中，三项技能估计与任务成功（选出最佳材料）的相关 r = 0.447 / 0.393 / 0.523 [A1, p.14]。
- **Construct validity（构念）**：弱。论文展示"能力估计能区分不同响应模式""技能间相关结构有解释"（如 VOTAT 与材料完整度相关仅 0.137）[A1, p.14]，但这些是 post-hoc 描述，没有外部阅读/认知构念证据。

## 1.14 主要发现

- 参数恢复良好；样本量、序列长度增大→精度提升；先验信息影响小；能力维度相关越高，各维度的估计越受益 [A1, p.8, Table 2]。
- 橄榄油任务：队内两维能力相关 r = 0.23**（p<.01），被解释为 dyad 成员相互影响 [A1, p.12]。
- 保温瓶任务：三项技能相关 0.137–0.469，技能与任务结果相关 0.393–0.523；模型能区分"系统性实验 vs 非系统性成功"等定性差异 [A1, p.14]。

## 1.15 局限

**Paper-stated**：维度需先验指定（确认式框架），如何确定维度/比较候选结构留待未来 [A1, p.15]；不含时间信息（留作扩展）[A1, p.15]；需要专家定义状态与 I⁺（大状态空间靠数据驱动方法补救）[A1, p.15]。

**Transfer limitations（迁移到英语阅读）**：
- 阅读任务没有 FSA 式的状态结构，"正确状态转移"概念在 scroll/underline/viewport 上无定义；
- 即使把"当前题目+已回答内容"编码成状态，I⁺ 标注也需要逐一人工判断"这个动作对哪项阅读技能是正确/错误的"——成本极高且主观；
- 单任务建模限制：每篇 passage 需要单独定义，跨 passage 的共享能力估计需要额外的等值化设计（论文未演示）。

## 1.16 迁移到我们的英语阅读系统

**可以直接迁移**：
- "动作选择 × 多维能力"的 multinomial logit 数学形式（Eq. 2）。**前提是动作有明确正确性**：例如 option_elimination_toggled（划掉错误选项 vs 划掉正确选项）、answer_option_clicked（选中正确选项 vs 错误选项）、underline_created 于关键句。这些可以定义"正确/错误/无关技能"三元标注，构成阅读技能的 I⁺ 矩阵。
- 多维能力 + 维度协方差的贝叶斯估计框架：可用于未来估计多技能（information locating / inference 等）的**相关结构**。
- STCCS 可视化思路（能力 → 转移概率曲面）可用于向教育者解释"哪些行为与哪项技能相关"。

**需要修改后迁移**：
- 原论文：固定 FSA 状态 + 专家定义的 I⁺。
- 我们：不同题目的句子/段落/选项对象不同；scroll/viewport/pointer 无正确性。
- 因此需要：**(a)** 从 physical action ID → **object-centric / semantic action 表示**（如 scroll 落到"第几段/哪句话"、underline 标注"哪个命题"）；**(b)** 只对"有正确性的动作类"（选项消除、选答、改答）建立 I⁺；**(c)** 把"状态"从系统配置重定义为"阅读进度/作答进度"这类**信息状态**（类似 A4 的信息状态 A–D 思路，见 §4）；**(d)** 对无正确性动作引入单独的观测模型（A 组无现成方案，需 B/D 组文献）。

**不适合迁移**：
- 直接对整条 raw event 序列（scroll sample / pointer sample / viewport）套 MSRM——没有状态、没有正确性，模型没有入口。
- 把"滚动到某段"当"正确/错误转移"——概念上不成立。

**该论文最适合解决的层**：`Cognitive Inference`（有正确性动作 → 多维技能）、`Student Model`（技能相关结构）、`Validity / Evaluation`（技能-结果相关验证的模板）。

**它解决不了什么**：raw events → 行为状态（无抽象机制）；scroll/underline 等无正确性行为的建模；focus/attention 不确定性问题；策略异质性（同质假设）；时间信息（未建模）。

# 2. A2 — HMM + 网络分析（Liu, Bulut, Cui, Gao, 2025, JCAL 41(1):e13089）

## 2.1 研究问题

三个研究问题：(1) problem-solving 过程中存在哪些隐藏反应状态（hidden response states）；(2) 这些状态之间如何关联；(3) 不同的 problem-solving 模式是否与表现水平相关 [A2, p.5, §2.4]。**相比此前方法（尤其 Xiao et al. 2021 的 HMM）新增的是**：在 HMM 隐藏状态之上，用 **Gaussian Graphical Model（GGM）分析隐藏状态之间的相似关系**，并用 **Polya 四步问题解决理论**给状态贴上认知解释——论文自称"首次用网络分析辅助解释 HMM 隐藏状态" [A2, p.14, §5.2]。

## 2.2 数据结构

- **一个 observation**：一次动作事件（PIAAC 日志中已编码的语义动作，如 MAIL_VIEWED、COMBOBOX、DOACTION）。
- **一个 action**：动作序列中的元素，`Y = {y₁,…,y_n}`，同一动作可重复出现 [A2, p.5, §3.2.1]。
- **action vocabulary**：由 OECD 日志提供的语义动作类别（论文列出：MAIL_VIEWED、TOOLBAR、ENVIRONMENT、HISTORY_ADD、DOACTION、COMBOBOX、MAIL_DROP、MAIL_MOVED、KEYPRESS、FOLDER_VIEWED、CONFIRMATION_OPENED/CLOSED、NEXT_ITEM、BUTTON、TEXTLINK 等）[A2, p.8-10, Fig. 5-6, Table 1]。
- **数据形式**：event/action sequence（有序），**HMM 分析中不使用时间戳**（论文在引言把"时间相关数据"列为单独一类，只作为 engagement 指标讨论 [A2, p.2, §1]）。
- **是否含 response correctness**：含（作为分组的正确/错误组变量）。
- **task/item ID**：两个 item：U02（难，约 10% 答对）、U01b（易，约 50% 答对）[A2, p.5, §3.1]。
- **学生级变量**：HMM 不使用背景变量（论文把按背景分组列为未来工作 [A2, p.14, §5.1]）。
- **多个任务**：每个 item **单独**拟合一个 HMM，不做跨 item 联合。
- **样本**：U02 正确组 62 人、错误组 438 人；U01b 正确组 290 人、错误组 369 人 [A2, p.5, §3.1]。

**简化示例**：U02 任务中一个学生的动作序列形如 `[MAIL_VIEWED, MAIL_VIEWED, DOACTION, COMBOBOX, CONFIRMATION_OPENED, ...]`。

## 2.3 预处理 / 动作编码

- PIAAC 原始日志已经过 OECD **预处理成语义动作类别**（论文直接说"recorded actions are defined as a string of actions in order" [A2, p.5]；Table 1 数据显示"preprocessed from the raw PISA/PIAAC log file data"的说法在 A5 论文出现，A2 对 PIAAC 同样依赖 OECD 的编码）。
- 不丢低频动作（interpretation 时聚焦"main actions"即 emission 概率高的动作）。
- 不聚合、不做状态编码。
- **状态数选择**：1–10 个状态用 AIC/BIC 选；U02 选 9 态、U01b 选 5 态。但注意：**AIC/BIC 随状态数增加持续下降**，作者转而参考 Xiao et al. (2021) 对 U19a/b 找到 7–8 态的结果来做合理性论证 [A2, p.7, §3.3；p.8, §4.1]。
- 需要 domain expert？观测层不需要；**解释层**需要理论框架（Polya）。

**关键点**：模型真正吃进去的是**已经是语义抽象后的动作序列**（OECD 编码），不是 raw clickstream。这对英语阅读项目意味着：如果我们用 HMM，需要自己先做 raw event → 语义动作这一步。

## 2.4 模型变量

| 类型 | 变量 | 说明 |
|---|---|---|
| 可观测 | Y = {y₁,…,y_n} | 动作序列（语义动作） |
| 可观测 | 正确/错误组 | 分组变量（模型外） |
| 潜在 | X = {x₁,…,x_n} | 隐藏状态序列（Markov 链） |
| 参数 | 初始状态分布 π | HMM 参数 |
| 参数 | 发射矩阵 B | P(动作 | 状态)，用于状态相似性分析 |
| 参数 | 转移矩阵 A | P(状态_{t+1} | 状态_t) |
| （GGM 阶段） | 精度矩阵 K | 隐藏状态间的偏相关网络（由发射矩阵算） |

## 2.5 模型机制

### 2.5.1 生成过程

> 标准的离散时间一阶 HMM：隐藏状态链 X 是一阶 Markov 链；给定隐藏状态，观测动作条件独立，每个动作以发射概率 P(y|X) 产生。模型（经 hmmlearn 估计）输出初始分布、发射矩阵、转移矩阵；再用 Viterbi 求每个学生最可能的隐藏状态序列。

### 2.5.2 数学结构

**HMM（§3.2.1）**：`{X_k, Y_k}, k≥0` 是二值离散时间过程；`{X_k}` 是 Markov 链；给定 `{X_k}`，`{Y_k}` 条件独立且只依赖当前 X_k（Cappé et al., 2005 的定义，论文 Fig. 2）[A2, p.6]。

**GGM（glasso）**：`L(K) = log det(K) − trace(SK) − λ Σ|k_ij|`（Eq. 1，图形 lasso 的惩罚对数似然）[A2, p.6, Eq. 1]；`EBIC = −2L(K) + E·log(n) + 4γE·log(p)`（Eq. 2，γ=0.5）[A2, p.6, Eq. 2]。节点 = 隐藏状态；**GGM 的输入数据 = 发射矩阵**（状态×动作的发射概率），求状态间的偏相关 [A2, p.7, §3.3]。

- 语义：GGM 把"哪些隐藏状态在动作倾向上相似（在控制其他状态后仍相关的）"识别出来；转移矩阵则给出状态间的实际转移路径。**网络分析在 HMM 后承担"状态相似性 + 模式可视化"功能**，不承担任何估计/预测功能。

## 2.6 时间建模

- 动作顺序：考虑（序列）。
- 真实 timestamp / duration / inter-event time：**均不考虑**。HMM 是 discrete-time（每个动作一步）。时间数据只在引言被提及为另一类过程数据。

## 2.7 潜在状态

- 隐藏状态是**统计潜在状态**（HMM 状态），数据驱动产生，数量由 AIC/BIC + 先前文献确定。
- **语义**：论文称其为"response status / 认知反应状态（cognitive response state）"，但**明确承认认知解释是事后（post-hoc）**：作者写道"as a data-driven method, HMM requires researchers to utilize theoretical and statistical tools to explain these hidden states. Otherwise, hidden states identified by HMM cannot be linked to cognitive processes" [A2, p.2, §1]。状态标签（如"Understanding the problem"）由 Polya 四步模型事后赋予 [A2, p.9, Table 1]。
- 状态是**全局共享**的（所有学生同一状态空间）；学生在状态间转移；状态是**item-specific**（每个 item 单独拟合，U02 9 态 / U01b 5 态）。
- 状态数与 task 相关（难任务更多状态）[A2, p.8]。

## 2.8 能力 / 潜在特质

- **模型内没有任何能力/特质变量**。隐藏状态是唯一潜在结构。
- 表现（正确/错误）只是**外部分组变量**：对正确组、错误组各拟合一个 HMM，然后比较状态结构/转移路径。
- **Process → Ability 链路：不存在**。是 `process data（动作序列）→ [HMM] → 隐藏反应状态 → [GGM + Polya 事后解释] → 模式`，表现与模式的关联是**组间描述性比较**（相关/定性），不是由模型估计的能力。

## 2.9 行为异质性

- 只在**正确/错误二分**层面处理异质性（两组分别拟合、状态数相同但结构不同）。组内假设同质（共享一个 HMM）。无 latent class、无 per-student 参数。

## 2.10 题目 / 任务效应

- 每个 item 单独拟合，状态空间 item-specific，无跨 item 模型、无难度参数。
- action space 要求：同一 item 内动作词汇一致即可。
- **新 item**：必须重定义动作词汇、重拟合 HMM、重选状态数。论文自己在 limitation 里承认"hidden states are highly dependent on the sequence of actions, which might not be applicable to items that measure problem-solving skills in other technology-enriched environments" [A2, p.14, §5.1]。

## 2.11 参数估计 / 训练

- 用 Python `hmmlearn` 包估计（论文未详述算法，标准 HMM 用 Baum–Welch EM）；Viterbi 解码 [A2, p.7, §3.3]。GGM 用 R `bootnet`/`qgraph`（EBICglasso）[A2, p.7]。
- 数据需求：论文未报告模拟/恢复研究；U02 正确组仅 62 人也估计成功，说明对数据量相对宽容。
- **online inference**：论文未讨论。原理上前向算法可在线算 P(状态_t | 历史)，但论文未涉及。
- **新学生**：无 per-student 模型可更新；新 item：整体重拟合。

## 2.12 可识别性 / 假设

- 一阶 Markov 假设、给定状态观测条件独立、状态转移齐性（stationary）、状态数先验固定（AIC/BIC 选择）、discrete-time、隐藏状态全局共享。
- **在英语阅读上可能不成立的**：一阶 Markov（阅读动作依赖更长历史）；stationarity（学生在任务后期行为节奏不同）；观测分布对动作词汇的敏感性（我们 raw 事件词汇量大且稀疏）；状态数选择的随意性（AIC/BIC 不收敛到唯一解）。

## 2.13 评估

- **Statistical validity**：只有 AIC/BIC 用于选状态数（不是拟合优度检验）；无参数恢复模拟。
- **Predictive validity**：无（无预测、无分类准确率、无外部相关）。
- **Construct validity**：**以事后解释为核心**——用 Polya 模型给状态贴标签、比较正确/错误组的网络与路径；用与既往 n-gram 研究（Liao et al. 2019; Wang et al. 2023）的"关键动作一致性"来支持解释的可信度 [A2, p.13, §5]。**这不是构念有效性的实证证据，而是研究者解释**。

## 2.14 主要发现

- U02 正确组：网络更简单（3 对相似状态）、转移路径更连贯（State 1→…→State 8，State 9→State 1 "回看→理解"）；错误组：更多相似状态、状态更孤立、转移更杂乱、冗余动作更多 [A2, p.10-11, §4.3-4.4, Fig. 7-8]。
- U01b 正确组无相似状态（"平滑解决"），错误组有一对相似状态 [A2, p.11, Fig. 9]。
- 关键动作（MAIL_VIEWED、COMBOBOX 等）与既往研究一致 [A2, p.13]。
- **全部为描述性结论，无 effect size、无统计检验**。

## 2.15 局限

**Paper-stated**：只分析两个 PSTRE item，状态高度依赖动作序列、难以迁移到其他环境；美国样本 + 2012 年数据限制推广；未按背景变量比较 [A2, p.14, §5.1]。

**Transfer limitations（迁移到英语阅读）**：
- 状态语义完全依赖动作编码质量：我们需要自己做 raw→语义动作的映射，而 HMM 结果对该映射极其敏感；
- 状态数选择没有原则性准则（论文实际靠文献参考）；
- 无任何能力/技能估计——只能做"正确组 vs 错误组"描述，对我们的"技能掌握"目标帮助有限；
- 认知解释依赖 Polya 四步——阅读没有对应的公认四步框架（需要 B 组提供阅读过程理论）。

## 2.16 迁移到我们的英语阅读系统

**可以直接迁移**：
- HMM + Viterbi 的"从动作序列发现隐藏行为状态"机制，可直接用于我们的**语义化后的动作序列**（如 question_navigated、option_elimination_toggled、underline_created、answer_changed 等已离散化的动作）。
- GGM/网络分析状态相似性 + 转移路径可视化：用于向研究者展示"阅读模式"和组间差异。
- "正确/错误组分开拟合再比较"的**描述性验证模板**。

**需要修改后迁移**：
- 原论文：OECD 已编码的语义动作 + Polya 解释。
- 我们：raw events（scroll sample、pointer sample、viewport）**必须先切成语义动作**（需要 D 组文献支持的分割方法），才能进 HMM；"隐藏状态"的解释需要一个**阅读过程理论**（如 search→extract→integrate→verify，待 B 组文献），替代 Polya。
- 需要把"per-item 单独拟合"改为"跨 passage 的共享状态空间或分层设计"（HMM 本身无此机制）。

**不适合迁移**：
- 把 HMM 当能力测量模型——它没有能力参数；
- 对原始 pointer/scroll 流直接跑 HMM——词汇爆炸 + 状态无意义。

**该论文最适合解决的层**：`State Reconstruction`（隐藏行为状态）、`Strategy / Process Mining`（转移路径）、`Validity / Evaluation`（组间描述性验证）。

**它解决不了什么**：能力估计、多技能测量、时间建模、新 item 泛化、行为→认知的构念有效性（作者自己承认是事后解释）。

# 3. A3 — Mix1P-SR（Xiao & Liu, 2025, Fudan Journal of Humanities and Social Sciences 18:79–113）

## 3.1 研究问题

针对 SR 类模型"假设学生同质"的共同局限 [A3, p.81, §1]，提出 **mixture one-parameter state response（Mix1P-SR）模型**：假设学生属于**离散潜在类别**，各类别对任务状态的响应倾向（state easiness 参数 β_ksg）不同、能力分布不同，从而在估计个体潜在能力的同时发现异质性行为模式。论文的目标是：(1) 提出模型与 MCMC 估计；(2) 模拟验证分类与参数恢复；(3) PISA 2012 实证展示两类行为模式及其与结果的关系。

## 3.2 数据结构

- **一个 observation**：学生 i 在任务 k 中处于状态 s 时对下一状态 s′ 的一次选择。
- **一个 action**：状态转移（等价于"选择下一个可达状态"）[A3, p.82, §2.1]。
- **状态数/action vocabulary**：模拟任务 T1 9 态、T2 15 态 [A3, p.87-88, §3.1, Fig. 1]；实证 PISA TICKETS 第 1 题 21 态、第 2 题 22 态（第 2 题按信息状态拆出 S7_1/S7_2）[A3, p.97, §4.1]。
- **数据形式**：state sequence（有序），**不含时间戳**（原始过程数据有时间戳但模型不用 [A3, p.80, §1]）。
- **是否含 response correctness**：结果分数进模型外验证（分类 × 结果交叉表）[A3, p.101, Table 4]；模型内需要**每个状态每个可达动作的正确/错误标注**。
- **task/item ID**：K 个任务，实证分析 TICKETS 前两个 item 的联合数据。
- **学生级变量**：无。
- **多个任务**：K 任务联合建模，给定 θ_i 时任务间条件独立 [A3, p.83, Eq. 3]。
- **样本**：27,616 名学生完成两任务；序列长第 1 题 5–146（均值≈7，中位 6）、第 2 题 5–91（均值≈10，中位 6）[A3, p.97]。

**简化示例**：学生动作流 → 状态序列 `S1 → S11 → S12 → S14 → S16 → S21`（TICKETS 第 1 题最优路径）；每一步面临一个可达集，每个可达态被标注正确/错误 [A3, p.104-105, Table 5]。

## 3.3 预处理 / 动作编码

- 与 A1/A4 相同：**必须预先人工定义** (1) 所有问题状态；(2) 每状态的可达状态集；(3) 每个可达状态的正误（Iss′ ∈ {0,1}）。任务规则 R 在正式分析前设定 [A3, p.83, §2.2]。FSA 任务可直接由设计定义；ill-defined 任务需要专家手工定义，"在大规模评估中困难且昂贵"，作者建议未来用数据驱动算法识别子阶段 [A3, p.103, §5.1]。
- 实现细节：每条序列只取前 200 个状态（超长序列 <1%，不影响估计）[A3, p.89, §3.2]。
- **模型吃进去的是"人工抽象后的 state sequence + 人工正误标注"**，不是 raw process data。

## 3.4 模型变量

| 类型 | 变量 | 说明 |
|---|---|---|
| 可观测 | y_ik（状态序列） | 学生 i 任务 k 的状态选择序列 |
| 可观测 | R（任务规则） | 状态集、可达集、正误标注 |
| 潜在 | θ_i | 潜在能力（连续），类别条件分布 N(0, σ²_g) |
| 潜在 | c_i | 潜在类别成员（离散） |
| 潜在 | σ²_g | 各类别能力方差 |
| 参数 | β_ksg | 状态 s、任务 k、类别 g 的"易度"参数（类别专属） |
| 参数 | π_g | 类别混合比例 |

## 3.5 模型机制

### 3.5.1 生成过程

> 学生 i 先以概率 π_g 落入类别 g，类别决定其能力分布 θ_i ~ N(0, σ²_g) 和每个状态 s 的易度参数 β_ksg。之后每个学生在任务 k 中逐步做选择：处于状态 s 时，对每个可达状态 s′，**选择权重 = exp[(β_ksg + θ_i)·Iss′]**——正确选项（I=1）得权重 exp(β_ksg + θ_i)，错误选项（I=0）得权重 exp(0) = 1；归一化后采样下一个状态。整条状态序列由这些选择的乘积构成；各任务条件独立。

### 3.5.2 数学结构

**混合模型（Eq. 1）**：
```
P(y_{ik(j+1)} = s′ | y_ikj = s, θ_i, β_ksg, R) = Σ_g π_g · P(y_{ik(j+1)} = s′ | y_ikj = s, θ_i, β_ksg, c_i = g, R)
```
[A3, p.83, Eq. 1]

**类别内 divide-by-total（Eq. 2）**：
```
P(y_{ik(j+1)} = s′ | y_ikj = s, θ_i, β_ksg, c_i = g, R) = exp[(β_ksg + θ_i)·Iss′] / Σ_{r∈M_S} exp[(β_ksg + θ_i)·Isr]
```
[A3, p.83, Eq. 2] 其中 Iss′ = 1 若 s′ 相对 s 更接近目标态，否则 0。

**乘法形式（不是加法）**：正确动作（I=1）的 score = exp(β_ksg + θ_i)，错误动作（I=0）的 score = exp(0) = 1。β_ksg 是该状态下"选正确动作"的基线易度，θ_i 是能力，两者共同提高正确动作相对错误动作被选择的概率。**为什么必须写成 exp[(β+θ)·I] 而不是 exp(β + θ·I)**：β 只按当前状态 s 索引（每状态一个易度、不按目标状态索引），若写成加法形式，同一状态下所有候选动作共享同一个 β，softmax 分子分母里的 β 会相互抵消，β 根本无法充当"状态易度"参数。这是模型可识别性的必要结构（A4 论文在 Eq. 1 后明确写道：正确选择时 numerator = exp(βks + θi)，否则 numerator = exp(0) = 1 [A4, p.260]）。

**全序列概率（Eq. 3）**：
```
p(y_i | θ_i, β₁,…,β_G, R) = Σ_g π_g · ∏_k ∏_{j=1}^{T_ik−1} P(y_{ik(j+1)} | y_ikj, θ_i, c_i=g, β_kg, R)
```
[A3, p.83, Eq. 3]

**后验（Eq. 4）**：`p(U|Y,R) ∝ p(Y|c,θ,β,R)·p(θ|τ,c)·p(τ)·p(β)·p(c|π)·p(π)` [A3, p.84, Eq. 4]。先验：c_i ~ Multinomial(π)；π ~ Dirichlet(0.01)；θ_i|c_i=g ~ N(0,σ²_g)；σ²_g ~ Inv-Gamma(4,3)；β_ksg ~ N(0,1) [A3, p.84, Eqs. 5-9]。

- 识别：每类能力均值固定为 0（μ_g=0 ∀g）[A3, p.83]。
- **类别差异 = 每类一套 β_ksg + 不同的能力方差**。这是一个"Rasch 式"（每状态一个易度、无区分度）模型。

## 3.6 时间建模

- 动作顺序：考虑（状态序列，Markov 通过状态承载累计信息）。
- timestamp / duration / inter-event time：**均不使用**。discrete-time。
- 论文强调状态是"从开始到当前的累计系统变化"，因此"吸收了很大一部分动作间的时间依赖" [A3, p.82, §2.2]——但这是**顺序/累计语义**上的依赖，不是真实时间。

## 3.7 潜在状态

- 无隐藏 Markov 状态。"状态"是可观测的任务状态（专家定义）。潜在结构是**能力 θ 与类别成员 c**。
- 类别是**数据驱动发现的潜在类别**（G 由模型选择决定，实证选 2 类）；类别解释是 post-hoc（通过 D_ks 指数和状态行为描述，如"Class 1 更擅长判断与纠错"）[A3, p.99-100, Table 3]。

## 3.8 能力 / 潜在特质

- **单维**连续能力 θ_i，student-level，类别条件分布（各类别方差不同，均值同固定为 0）。
- 能力通过正确性指示 Iss′ 进入**动作选择**：正确动作 score = exp(β_ksg + θ_i)、错误动作 score = 1，θ 越高正确动作相对错误动作越容易被选（β_ksg 是该状态下选正确动作的基线易度，与 θ 共同作用）。
- 类别成员同时影响能力分布与状态易度 → 能力和"行为模式"在模型里**相互纠缠**（类别差也可能部分反映能力差）。
- **Process → Ability 链路**：`state sequence → [任务规则 R + 正误标注] → 类别内 multinomial logit → (θ_i, c_i)`。

## 3.9 行为异质性

- **核心卖点**：离散潜在类别捕捉异质行为模式。不同类别有**不同的状态易度剖面**（β_ksg）和**不同的能力分布**（σ²_g）。
- 论文指出这与 mixture IRT（Bolt et al. 2001; Rost 1990）同源，用过程数据本身的维度来发现组结构 [A3, p.82, §2.2]。
- **但注意**：类别内的行为仍是同质的（共享 β_ksg）；"策略"是以类别为单位区分的，不是 per-student 的。

## 3.10 题目 / 任务效应

- K 任务联合建模（局部独立），每任务有自己的状态集与 β_ksg；action space 任务间不必一致。
- 状态易度参数**类别专属**（β_ksg），体现"不同类在不同步骤的差异"。
- **新 item**：需重新定义状态与正误标注，并估计新任务的 β_ksg；共享 θ、π 使得**结构上可扩展**（加入新任务 = 加一组状态参数）。但正确性标注仍需人工。

## 3.11 参数估计 / 训练

- **Bayesian MCMC**：Metropolis–Hastings-within-Gibbs。5 步采样：类别成员（全条件）→ θ_i（MH）→ β_ksg（MH）→ π（Dirichlet 全条件）→ σ²_g（Inv-Gamma 全条件）[A3, p.85-86, Eqs. 10-16]。
- 3 链 × 20,000 迭代，前一半 burn-in，每 10 次保留 [A3, p.89]。label switching 检测与跨链标签匹配 [A3, p.87]。
- 收敛判据：PSRF < 1.2 [A3, p.89]。
- **数据需求（关键工程属性）**：模拟显示**平均序列长度最好 ≥ 30**、样本量建议 ≥ 1000–2000；短序列时能力恢复很差（两类别模型短序列 RMSE ≥ 0.57）[A3, p.92-94, Fig. 4]；高类别相似性（ρ=0.8）+ 小样本 → 不收敛（表 1 中不收敛率最高 42%）[A3, p.91, Table 1]。
- **online inference**：论文未实现（MCMC 批处理）。任务参数（β、π、σ²）离线标定后，新学生理论上可做固定参数下的后验更新 / MAP / EAP（结构可改造、论文未演示）。**新 item**：需加状态参数重估。

## 3.12 可识别性 / 假设

- 预定义任务规则 R（状态、可达、正误）—— ground truth 需求。
- Iss′ 二元（0/1），每状态一个易度参数（无区分度）。
- 任务间局部独立；状态层面 Markov（状态承载累计信息）。
- 各类别能力均值固定 0（识别）；类内能力正态。
- **在英语阅读上可能不成立的**：Iss′ 二元正误对阅读动作无定义；"每状态一个易度"对无正确性的行为不适用；**类别数量的可识别性**（模拟显示 3 类别模型对 2 类别数据不收敛，类别数高估会导致不收敛/无法解释 [A3, p.90, footnote]）。

## 3.13 评估

- **Statistical validity**：模拟参数恢复（状态参数 bias ∈ [−0.08, 0.03]，多数条件下与真值相关 >0.95、RMSE < 0.25 [A3, p.92, §3.4.3]；能力 bias ∈ [−0.011, 0.011]）；分类准确率（序列越长、类别相似性越低越高，Fig. 2 [A3, p.91]）；模型选择五个指标（AIC/BIC/SABIC/DIC/PsBF）正确率表 [A3, p.95-96, Table 2]。
- **Predictive validity**：类别成员 × 任务结果交叉表：Class 1 两任务全对占 54.53%，Class 2 几乎无人两任务全对（0.00%）；Class 2 中 58.05% 两任务全失败 [A3, p.101, Table 4]。**这是强的"类别-结果"关联，但属于描述性/分类相关，不是预测验证**。
- **Construct validity**：靠 D_ks 指数 + 对类别的定性描述（"更会思考与判断"）。无外部阅读构念。作者承认类别解释需要进一步验证。

## 3.14 主要发现

- 实证选 2 类（π₁=0.492, π₂=0.508 [A3, Table 9, p.108]），状态参数跨类相关 0.51（中等）[A3, p.98]。
- 关键状态差异：任务 2 状态 S8 的 D=0.792（Class 1 倾向 CANCEL 重来，Class 2 直接 BUY 结束）；S7_2 的 D=0.627（Class 1 会选价格未知的另一票种或正确比价）[A3, p.99-100, Table 3]。
- Class 1 能纠错（在购买界面 CANCEL 重来），Class 2 一旦偏离正确路径几乎不纠错 [A3, p.100]。

## 3.15 局限

**Paper-stated**：必须预定义状态/可达/正误（ill-defined 任务成本高，建议数据驱动子阶段识别）[A3, p.103]；各类别能力均值固定 0 导致参数不可跨类直接比较（需共同度量）[A3, p.103-104]；类别相似性度量（相关系数）只反映形态不反映抬升，且状态间非独立 [A3, p.104]；个别能力参数双峰后验（类别切换）[A3, p.103]；数据需求大（长序列、足量样本）。

**Transfer limitations（迁移到英语阅读）**：
- 需要"正确动作"标注——阅读行为不满足；
- 序列长度需求（≥30）与真实阅读会话长度可能不匹配（每次答题动作数可能远少于此，尤其单一 passage 多小题场景）；
- 类别解释依赖行为语义，而阅读行为的语义标注缺乏公认框架；
- 能力与类别纠缠：无法分离"低能力"与"不同策略"（A3 已隐含这种混淆）。

## 3.16 迁移到我们的英语阅读系统

**可以直接迁移**：
- 潜在类别建模思路本身："同样做阅读题，存在不同行为类别"——可直接用于发现"先读后答 vs 边读边答 vs 快速扫描回读"等策略类别（对应你描述的 Student A/B/C 异质性）。
- 类别 × 结果交叉验证模板：用答案正确性做外部验证。
- D_ks 类别的"状态级诊断"索引：找出"哪个状态/哪类动作上两类差别最大"。

**需要修改后迁移**：
- 原论文：状态 = 任务系统配置（售票机界面）；正误标注 Iss′。
- 我们：需要把"状态"重新定义为**阅读/作答进度状态**（如"当前题号 + 已选答案 + 已划掉选项集合 + 已查看的段落范围"），并且**只对选项类动作给正误标注**（划掉正确选项 vs 划掉错误选项；最终答案对错）。
- scroll/viewport/underline 不进入正误模型，只能作为类别特征的**协变量/观测附加层**（A 组无现成机制）。
- 类别数量需用 PsBF/DIC 等稳健选择（模拟显示短序列下 BIC/SABIC 差）[A3, p.95-96, Table 2]。

**不适合迁移**：
- 把每类一个 β_ksg 直接套到"滚动行为"上（无正误）；
- 期望模型自动区分"能力低"与"策略不同"——它给出的是两者的混合体。

**该论文最适合解决的层**：`Strategy / Process Mining`（策略类别）、`Cognitive Inference`（类别→策略性判断的有限推断）、`Student Model`（类别结构）、`Validity / Evaluation`（类别-结果交叉验证）。

**它解决不了什么**：多技能测量（单维能力）；无正确性行为的建模；时间；新 passage 的自动泛化；把类别解释为认知状态的构念有效性。

# 4. A4 — SR 模型（Xiao & Liu, 2024, Behavior Research Methods 56:258–277）

## 4.1 研究问题

提出 **State Response（SR）测量模型**：把每个任务状态当作一个"item"，把每次动作选择当作对该状态的"response"，用 IRT 式模型同时估计**个体潜在能力 θ** 与**每个任务状态的状态易度 β_ks**。**相比 CTDC（Chen 2020）的 DC 子模型（任务级单一易度）新增的是**：把易度下沉到**状态级**，刻画任务的过程特征 [A4, p.259, §Introduction；p.262]。论文声称 SR 是 DC 的一般化（DC = 同一任务内所有状态易度相等的约束版本）。

## 4.2 数据结构

- **一个 observation**：学生 i 在任务 k 处于状态 s 时对下一状态 s′ 的一次选择。
- **一个 action**：状态转移选择。状态 = FSA 系统状态（累计结果）。
- **状态数**：模拟任务 T1 9 态、T2 15 态 [A4, p.263, Table 1]；实证 PISA TICKETS 第 1 题 21 态、第 2 题 21 态（模型分析时 S7 按信息状态拆为 S7_1/S7_2）[A4, p.267-268]。
- **数据形式**：state sequence（有序），**不含时间戳**。
- **是否含 response correctness**：含结果分数，用于外部验证（相关性 + 回归）[A4, p.268-270]。模型内需要**每个状态每个可达动作的正误标注**。
- **task/item ID**：K 任务，实证 2 个 item 联合分析（因为"长序列对能力估计更好"）[A4, p.268, §Analysis]。
- **学生级变量**：无。
- **多个任务**：K 任务，给定 θ_i 条件独立（Eq. 2）[A4, p.262]。
- **样本**：27,616 名学生；序列长第 1 题 5–146（均值 7.39、中位 6）、第 2 题 5–91（均值 10.05、中位 6）[A4, p.268]。

**简化示例（TICKETS 第 1 题）**：状态 S1（全空）→ 可达正确 S11、错误 S1/S2；S11 的 I = 1 表示选 COUNTRY TRAIN 正确。模型在每步比较"选正确选项 vs 选错误选项"的相对倾向 [A4, Appendix Table 9]。

## 4.3 预处理 / 动作编码

- 与 A1/A3 相同：**预先人工定义状态、可达集、正误**（R）[A4, p.261]。FSA 任务中状态与转移内建于设计，研究者只需定义正误；非 FSA 任务需要内容专家手工定义 + 数据重编码，作者建议可用 HMM 辅助识别子阶段 [A4, p.271, §Discussion]。
- **关键机制——事件历史处理**：当同一状态在不同"信息状态"（由先前事件决定）下正确/错误选项集合不同时，(a) 若正确/错误选项**数量**相同，仍视为一个状态、一个易度；(b) 若数量不同，则拆成**不同的状态、分别估计易度**（如 S7_1 / S7_2）[A4, p.261-262, Fig. 2]。这是把**时间依赖"折叠"进状态定义**的技巧。
- 只取每条序列前 200 状态（实现细节）[A4, p.264]。

## 4.4 模型变量

| 类型 | 变量 | 说明 |
|---|---|---|
| 可观测 | Y_ik（状态序列） | 学生 i 任务 k 的状态选择序列 |
| 可观测 | R（任务规则） | 状态、可达集、正误（Iss′） |
| 潜在 | θ_i | 潜在问题解决能力（单维） |
| 参数 | β_ks | 状态 s、任务 k 的状态易度参数 |
| （对照模型 DC） | β_k | 任务级单一易度（SR 的约束版本） |

## 4.5 模型机制

### 4.5.1 生成过程

> 学生 i 有能力 θ_i ~ N(0,1)。在任务 k 中逐步推进：处于状态 s 时，从可达集 M_s 中按 multinomial logit 选择下一状态；**选择权重 = exp[(β_ks + θ_i)·Iss′]**——正确选项（I=1）得权重 exp(β_ks + θ_i)，错误选项（I=0）得权重 exp(0) = 1。状态易度 β_ks 与能力独立，共同决定"选正确动作"的倾向。不同任务间条件独立。事件历史通过"信息状态"改变状态的正误结构。

### 4.5.2 数学结构

**选择模型（Eq. 1）**：
```
P(Y_ik(j+1) = s′ | Y_ikj = s, θ_i, β_ks, R) = exp[(β_ks + θ_i)·Iss′] / Σ_{r∈M_s} exp[(β_ks + θ_i)·Isr]
```
[A4, p.260, Eq. 1] Iss′ = 1（接近目标态）或 0。

**乘法形式（不是加法）**：正确动作（I=1）的 score = exp(β_ks + θ_i)，错误动作（I=0）的 score = exp(0) = 1。β_ks 是该状态下"选正确动作"的基线易度，θ_i 是能力，共同提高正确动作相对错误动作的选择概率。A4 论文在 Eq. 1 后明确写道：正确选择时 numerator = exp(βks + θi)，否则 numerator = exp(0) = 1 [A4, p.260]。

**与 A1（MSRM）参数化的关键区别**：A3/A4 的 β 只按**当前状态 s** 索引（每状态一个易度），因此必须是乘法形式 exp[(β+θ)·I]；若写成加法形式 exp(β + θ·I)，同一状态所有候选动作共享 β，softmax 会把 β 消掉、β 失去"状态易度"意义。**A1 的 λ_{j,k} 则按目标状态 k 索引（每条转移一个倾向参数），所以 A1 的加法形式 exp(λ_{j,k} + (I⁺_{j,k})ᵀ·θ) 是正确且可识别的**——这是两类参数化的本质差异，不要混用。

**跨任务似然（Eq. 2）**：`L(Y_i | θ_i, β₁,…,β_K, R) = ∏_k ∏_{j=1}^{J_ik−1} P(Y_ik(j+1)|Y_ikj, θ_i, β_k, R)`（给定 θ 任务条件独立）[A4, p.262, Eq. 2]。

**后验（Eq. 3–5）**：`p(θ,β|Y,R) ∝ p(Y|θ,β,R)·p(θ,β)`；先验 θ_i ~ N(0,1)、β_ks ~ N(0,1) [A4, p.262, Eqs. 3-5]。识别：θ 均值固定 0 [A4, p.262]。

- **与 DC（CTDC 动作子模型）的关系**：把同一任务所有状态易度约束相等即得 DC。论文的模拟与实证都显示：状态易度确实不同，SR 显著优于 DC（实证 AIC 595,405.04 vs 671,978.74；2ln(PsBF) = 87,921.69）[A4, p.268, Table 4]。
- 语义：β_ks 大 = 该状态"容易选对"；θ 大 = 同样状态下更倾向选对。**能力 = 在预先标注为正确的动作上的选择倾向**。

## 4.6 时间建模

- 动作顺序：考虑（状态序列）。
- timestamp / duration / inter-event time：**均不使用**。
- 时间依赖只通过两处"折叠"：(1) 状态 = 累计系统状态；(2) 信息状态拆状态。模型自身是离散、无时间的。

## 4.7 潜在状态

- 无隐藏 Markov 状态。可观测任务状态（专家定义）。唯一潜在变量是 θ_i（和 A3 的类别，但本论文不含类别）。
- 状态的正误结构随事件历史变化，通过"拆状态"解决——这是**把历史依赖结构化**，不是潜在状态。

## 4.8 能力 / 潜在特质

- **单维**连续能力 θ_i，student-level，均值固定 0。
- 通过正确性指示进入动作选择（Eq. 1）：正确动作 score = exp(β_ks + θ_i)、错误动作 score = 1，θ 越高正确动作相对错误动作越容易被选（β_ks 是该状态下选正确动作的基线易度）。
- **Process → Ability 链路**：`state sequence → [任务规则 R + 正误标注] → 选择概率 → θ_i`。
- **验证**：θ_SR 与两任务结果相关 0.769/0.785（DC 为 0.792/0.719）[A4, p.269, Table 7]；把 θ 回归到 PISA 整体问题解决表现，SR R²=0.384 vs DC R²=0.361 [A4, p.270, Table 8]。两个模型的能力估计相关 0.977 [A4, p.269]。

## 4.9 行为异质性

- **同质假设**：所有学生共享同一套 β_ks。论文未处理类别/策略差异（A3 是其后续扩展）。论文自己也承认"状态易度可能与具体事件有关"等限制 [A4, p.271, §Limitations]。

## 4.10 题目 / 任务效应

- K 任务联合建模（局部独立），每任务自己的状态与 β_ks；action space 任务间不必一致。
- 状态易度 = 每个状态的难度（**这是跨 item 最重要的机制**：不同任务难度通过状态易度体现）。
- **新 item**：需重定义状态与正误，估计新 β_ks；共享 θ 使结构上可扩展。但正误标注必须人工。

## 4.11 参数估计 / 训练

- **Bayesian MCMC**（MH-within-Gibbs）：θ_i（MH）、β_ks（MH）[A4, p.262-263, Eqs. 6-7]。3 链 × 10,000 迭代、前 2000 burn-in、每 5 保留；R̂ < 1.1 [A4, p.263-264]。
- 模拟：18 条件（3 样本量 800/1500/3000 × 3 序列长度 × 等/非等易度）× 50 重复。
- **数据需求**：样本量主要影响状态参数精度；序列长度主要影响能力精度 [A4, p.264]。
- **online inference**：论文未实现（MCMC 批处理）。任务参数（β_ks）离线标定后，新学生理论上可做固定参数下的后验更新 / MAP / EAP（结构可改造、论文未演示）。**新 item**：需重估 β_ks。

## 4.12 可识别性 / 假设

- 预定义状态/可达/正误（R）；Iss′ 二元（可扩展为 [0,1] 甚至可估计 [A4, p.271]）。
- 任务间局部独立；状态层面依赖通过状态承载。
- **静态参数假设**：能力和状态易度在解题过程中恒定 [A4, p.271]。
- 通常每状态一个易度。
- **在英语阅读上可能不成立的**：Iss′ 二元正误对阅读动作无定义；静态参数（阅读中技能/状态可能动态变化，且系统给出反馈时 A4 作者自承假设不成立 [A4, p.271]）。

## 4.13 评估

- **Statistical validity**：模拟恢复（状态参数 bias≈0、RMSE < 0.1；能力与真值相关 >0.8（非等易度）/ >0.9（等易度），bias ±0.01）[A4, p.264, Fig. 3-4]；模型选择指标支持真实模型（非等易度条件下五个指标 100% 选对 SR [A4, p.265, Table 2]）。
- **Predictive validity**：能力与任务结果相关（0.769/0.785）；回归整体表现 R²=0.384（SR）vs 0.361（DC）。**这是 criterion/predictive validity 的证据**，且展示 SR 比 DC 略强。
- **Construct validity**：通过"最优路径上的状态易度更高"（如 S16=2.578、S14=2.575）等**内容合理性的后验解释** [A4, p.268-269, Tables 5-6]；无外部阅读构念。

## 4.14 主要发现

- 实证中状态易度差异显著（同任务内 95% CI 几乎不重叠），最优路径状态易度最高 [A4, p.269, Tables 5-6]。
- 五个拟合指标全部支持 SR 优于 DC（AIC/BIC/ABIC/DIC/PsBF）[A4, p.268, Table 4]。
- 能力估计解释了 PISA 整体表现约 38% 方差（R²=0.384），优于 DC（0.361）[A4, p.270, Table 8]。

## 4.15 局限

**Paper-stated**：正误二元（可扩展）；信息状态拆状态是近似（完整的状态-历史专属参数会太复杂）；静态参数假设（有反馈的动态任务可能不成立）；稀有状态数据少 → 估计不稳（建议合并状态或正则化）[A4, p.271]；非 FSA 任务需专家定义状态（可用 HMM 辅助）。

**Transfer limitations（迁移到英语阅读）**：
- 正误标注需求同 A1/A3；
- 阅读中"状态"边界模糊（没有 FSA 式系统状态），把"阅读进度"编码成状态需要新的形式化（哪些维度进入状态定义：当前题号？已查看段落？已划选项？）——**这是 A 组论文未提供的设计**；
- 静态参数假设：学生读完一篇 passage 后技能/状态会变化；
- 单维能力：无法直接支撑多阅读技能。

## 4.16 迁移到我们的英语阅读系统

**可以直接迁移**：
- **Eq. 1 的选择模型**（状态易度 + 能力 → 正确/错误动作选择）几乎可直接用于有正确性的动作：option_elimination（划掉正确 vs 错误选项）、answer selection/change、underline 关键句（若可定义"关键性"）。
- "把事件历史折叠进状态定义"（信息状态 A–D 拆状态）的思路：可用来建模"学生是否已看到关键信息"这一状态维度——例如把"已查看证据句"编入状态，使动作正确性随历史变化。**这对阅读非常重要**：同样"选 B"，读过证据段 vs 没读过，认知含义不同。
- 状态易度 = 每个"阅读步骤"难度的机制：可用于诊断"哪一步（定位/整合/推断）学生最容易卡住"。

**需要修改后迁移**：
- 原论文：FSA 状态 + 专家正误标注。
- 我们：需定义阅读专用状态编码（如 `当前题号 × 已回答 × 已划掉集合 × 关键信息可见性`），并**只对选项类动作定义正误**；scroll/underline/pointer 作为附加观测，不进选择模型。
- 单维 θ 需升级为多维（用 A1 的 I⁺ 思路），或把不同技能动作分组估计。

**不适合迁移**：
- 对 scroll/viewport 等无正误行为直接套 Eq. 1；
- 期望单一静态能力解释整篇 passage 的阅读行为。

**该论文最适合解决的层**：`State Reconstruction`（信息状态折叠进状态）、`Cognitive Inference`（有正误动作 → 能力）、`Student Model`（能力）、`Validity / Evaluation`（能力-结果验证）。

**它解决不了什么**：无正误行为；多维技能；策略异质性（A3 补充）；时间；新 passage 自动泛化；聚焦不确定性问题。

# 5. A5 — CTDC 模型（Chen, 2020, Psychometrika 85(4):1052–1075）

## 5.1 研究问题

提出 **Continuous-Time Dynamic Choice（CTDC）测量模型**：把日志数据看作 **marked point process**，同时建模"下一步选什么动作"（条件密度函数）和"什么时候做"（ground intensity），从而用动作序列 + 时间戳**同时估计两个潜在特质**：问题解决能力 θ 与动作速度 τ [A5, p.1052-1053, Abstract]。相比 MDP-MM（LaMar 2018）与 IRT 类模型的新增：(1) 使用真实时间戳（连续时间）；(2) 通过预定义的动作有效性 Vj(Ft) 量化动作质量（比 MDP 的 Q-function 更简单、计算便宜）；(3) 可同时分析多个任务 [A5, p.1053-1054]。

## 5.2 数据结构

- **一个 observation**：一个事件（动作）**及其时间戳**。日志 = 双序列 (T, Y) = ((T_n), (Y_n))，T_n ∈ [0,∞) 单调递增，Y_n ∈ {1,…,J} 是事件类型（= 系统状态）[A5, p.1055, §2.2]。
- **一个 action**：事件 = 状态转移（如"点击 CITY SUBWAY"）。事件类型数 J = 任务状态数（TICKETS 每任务 21 态）[A5, Appendix Table 7]。
- **数据形式**：**event sequence + 连续时间戳**（表 1 示例：StID 17, Time 0 → 7.3 → 17.1 → 27.1 → 32.9，每行一个动作+状态）[A5, p.1057, Table 1]。
- **是否含 response correctness**：含（最终结果），用于验证；模型内需要**预定义动作有效性 V_j(F_t)**（二元：是否有助于最终成功，依赖事件历史）[A5, p.1057]。
- **task/item ID**：K 任务（局部独立），实证 2 个 item。
- **学生级变量**：无；潜在特质 (θ_i, τ_i) ~ N(μ, Σ)，均值固定 0 [A5, p.1058, p.1060]。
- **多个任务**：K marked point processes，给定 (θ,τ) 条件独立 [A5, p.1059]。
- **样本**：392 名完成两任务的美国学生（266 解出任务 1、115 解出任务 2、97 全解）[A5, p.1063]。模拟 N=100/400。

**简化示例**：`(0, S1) → (7.3s, S2) → (17.1s, S7) → (27.1s, S8) → (32.9s, S21 结束)`，其中 S8 表示已选 CITY SUBWAY+CONCESSION+DAILY，任务要求比价，未比较即 BUY 为无效动作 [A5, p.1057, Table 1]。

## 5.3 预处理 / 动作编码

- 原始日志**预处理**为"状态 + 标准化到任务开始的时间戳"（论文明确 Table 1 "preprocessed from the raw PISA 2012 log file data"）[A5, p.1057]。事件类型 = 专家定义的 21 个状态。
- **有效性 V_j(F_t)**：由任务设计给出（附录 Tables 8、9），**依赖事件历史**（信息状态 A–D：两个候选票价是否已知决定哪几个动作有效）[A5, Appendix Table 8]。**需要领域专家预先完整指定"任意历史下的任意动作是否有效"**。
- 时间到首次动作 T_{k1} 不建模（条件似然以其为条件）[A5, p.1060, p.1061]。
- 论文承认：有效性先验指定的要求限制了复杂任务的应用 [A5, p.1071, §6]。

## 5.4 模型变量

| 类型 | 变量 | 说明 |
|---|---|---|
| 可观测 | Y_k（事件类型序列）、T_k（连续时间戳序列） | marked point process 观测 |
| 可观测 | S_k(F_kt)（可达事件集）、V_kj(F_kt)（有效性） | 任务结构（专家给定） |
| 潜在 | θ_i | 问题解决能力特质 |
| 潜在 | τ_i | 动作速度特质 |
| 参数 | β_k | 任务级易度（动作选择子模型） |
| 参数 | γ_k | 任务级基线强度（时间子模型） |
| 参数 | Σ | (θ, τ) 的协方差 |

## 5.5 模型机制

### 5.5.1 生成过程

> 每个学生有二维潜在特质 (θ_i, τ_i) ~ N(0, Σ)。任务开始后，学生的行为由一个 marked point process 驱动：在任意时刻，当前事件历史 F_t 决定可达事件集 S_k(F_t) 与每个事件的有效性 V_kj(F_t)；下一步动作的类型按 multinomial logit（权重 = 有效性与 (β_k + θ_i) 的乘积）采样；动作发生的等待时间按指数分布，速率 = exp(γ_k + τ_i)。任务结束（到达终态）后无更多事件。多任务间条件独立。

### 5.5.2 数学结构

**动作选择子模型（Eq. 1）**：
```
f_k(j | t, F_kt, θ, β_k) = exp((β_k + θ)·V_kj(F_kt)) / Σ_{i∈S_k(F_kt)} exp((β_k + θ)·V_ki(F_kt))
```
[A5, p.1060, Eq. 1]（Boltzmann / divide-by-total 选择模型）。θ=+∞ → 总选最有效动作；θ=−∞ → 总选最无效动作；β_k+θ=0 → 均匀随机 [A5, p.1060]。

**时间子模型（Eq. 2）**：
```
λ_k(t | F_kt, τ, γ_k) = exp(γ_k + τ)
```
[A5, p.1060, Eq. 2]（常数强度 = 任务内恒定速度）。期望到下一动作时间 = exp(−γ_k − τ)。

**条件似然（L_ik）**：
```
L_ik(θ, β_k, γ_k) = ∏_{n=1}^{m_ik} f_k(y_ikn | t_ikn, F_kt, θ_i, β_k)
                 × ∏_{n=1}^{m_ik−1} exp(γ_k + τ_i)·exp(−(t_ik,n+1 − t_ikn)·exp(γ_k + τ_i))
```
[A5, p.1061, Eq. 3 上方]。**第二项是指数等待时间（inter-event time）的密度**——这是时间真正进入模型的地方。

**边际似然（Eq. 3）**：
```
l(β, γ, Σ) = Σ_i log ∫ [∏_k L_ik(θ, β_k, γ_k)] φ(θ|Σ) dθ
```
[A5, p.1061, Eq. 3]。固定参数 (β, γ, Σ) 用 **MML + EM** 估计；潜在特质用 **EAP** 估计 [A5, p.1061]。

- 关键结构：**动作选择只依赖能力 θ 和历史；时间只依赖速度 τ 和历史**——两者可分离 [A5, p.1059, Fig. 5]。这与 van der Linden (2007) 的 speed-accuracy 模型同构（动作↔作答、等待时间↔反应时）[A5, p.1062]。
- 无事件类型专属参数（避免高方差）[A5, p.1062]。最终结果 Z_k 是动作序列的确定性函数 → 给定 θ 时 Z_1,…,Z_K 条件独立，诱导出一个关于结果的非参数单调 IRT 模型 [A5, p.1062]。

## 5.6 时间建模

- **continuous-time**，使用真实 timestamp。
- **等待时间（inter-event time）**：显式建模（指数强度）——动作越快（τ 大），等待时间越短。
- **duration**：任务总时长由等待时间累计隐含（总时长分布见 Fig. 6），但**没有单独的状态驻留异质性**（常数强度假设）。
- **首次动作时间**：不建模（条件似然以 T_{k1} 为条件）[A5, p.1060]。
- 支持**右删失（right-censoring）**与任务缺失（MCAR）[A5, p.1070, §6]。

## 5.7 潜在状态

- **无隐藏状态**。事件类型 = 可观测系统状态。潜在变量是 (θ, τ) 两个连续特质。没有行为/认知潜在状态层。

## 5.8 能力 / 潜在特质

- **两个潜在特质**：能力 θ 与速度 τ，student-level，二元正态相关可估计（实证估计相关 −0.11，95% CI (−0.26, 0.04)，弱负且不显著）[A5, p.1064, Table 3]。
- θ 影响**动作选择**；τ 影响**动作时机**；无交叉（选择不依赖 τ、时间不依赖 θ）[A5, p.1059]。
- **Process → Ability 链路**：`log data（动作序列 + 时间戳）→ [预定义有效性 V + 任务结构] → 选择 multinomial logit + 指数等待时间 → (θ, τ)`。
- **验证**：θ 显著预测 PISA 整体表现（斜率 40.15, p<2e-16, R²=32.34%）；τ 单独不显著（p=0.69, R²=0.04%）；两特质一起时 τ 变显著（p=0.01），ΔR²=1.09%（95% bootstrap CI (0.03%, 3.44%)）[A5, p.1065-1066, Tables 4-5]。两任务联合分析 R²=33.43%，优于单任务（24.18%/23.78%）[A5, p.1066, Table 5]。
- **过程 vs 结果**：任务 2 的过程数据比二元结果多解释 6.31%（CI (0.11%, 13.60%)）；任务 1 没有额外信息（Δ=−0.19%）；两任务合计与两结果无显著差异（Δ=−0.63%）[A5, p.1066, Table 5]。**说明过程数据的信息增量取决于任务复杂度**。

## 5.9 行为异质性

- **同质模型**：所有学生共享 β_k、γ_k；无类别、无 per-student 行为参数。异质性只通过连续的 (θ, τ) 体现。
- 论文未讨论策略异质性。

## 5.10 题目 / 任务效应

- K 任务（局部独立）联合建模；每任务有自己的 β_k（易度）与 γ_k（基线强度）。
- 有效性 V 必须逐任务、逐事件历史给定（附录完整列出）。不同任务的状态空间/可达集可以不同。
- **任务级而非状态级参数**：同一任务内所有状态共享 β_k——**这正是 A4 批评的"DC 模型"**。作者在 A4 中被指出忽视了状态级过程特征。
- **新 item**：需预定义状态与有效性、估计 β_k/γ_k；共享 (θ,τ) 使结构上可扩展。有效性标注仍须人工。

## 5.11 参数估计 / 训练

- **MML + EM**（对 Σ 做数值/蒙特卡洛积分）；EAP 估计特质 [A5, p.1061]。
- 模拟 N=100/400，6 条件，50 重复；固定参数恢复合理、样本越大越准 [A5, p.1067-1068, Fig. 8]；**联合分析两任务比单任务更准** [A5, p.1068-1069, Figs. 9-10]。
- 作者自述 EM"对大过程数据可能不够快"，建议 MH–RM、stochastic EM、或 joint likelihood（更快，避免积分）[A5, p.1071]。
- **online scoring 路径在论文中最明确**：MML/EM 标定任务参数后，个体 (θ,τ) 用 EAP 一步估计（计算量小）[A5, p.1061]。论文未跑真正的在线实验，但"参数离线标定 → 个体快速打分"的机制是**论文显式实现**的（A1/A3/A4 在结构上亦可改造但论文未实现，见 §7 Q9）。
- 处理 MCAR 任务缺失与任务内右删失 [A5, p.1070]。
- **不推荐用于高风险测试评分**（时间子模型易误设）[A5, p.1071]。

## 5.12 可识别性 / 假设

- 局部独立（跨任务，给定特质）。
- **任务内可分离性**：选择只依赖 θ+历史、时间只依赖 τ+历史。
- 有效性 V 先验给定（ground truth）。
- 常数强度（任务内恒速）——指数等待时间，**明显简化**。
- (θ,τ) 二元正态、均值 0；首次动作时间被条件化。
- 无事件类型专属参数。
- **在英语阅读上可能不成立的**：常数强度（阅读中驻留高度异质：读长段 vs 快速扫）；"动作有效性"对 scroll/underline 无定义；指数等待时间假设（真实阅读动作间隔分布更重尾）；可分离性（阅读中"读得慢"可能与能力有关，θ 与 τ 的独立结构可疑）。

## 5.13 评估

- **Statistical validity**：模拟固定参数恢复（Fig. 8）、特质 EAP 的 MSE（Figs. 9-10）。无模型拟合优度检验（论文承认 marked point process 的 GOF 方法未成熟）[A5, p.1070-1071]。
- **Predictive validity**：θ/τ 回归整体表现（R² 分解）；过程 vs 结果的 R² 差异（bootstrap CI）。**这是最强的一套预测性验证**。
- **Construct validity**：对 β_k、γ_k 的解释（如任务 2 的 β 更大——"部分满足"更易、界面熟悉度 [A5, p.1064, §4.2]）；无外部构念。

## 5.14 主要发现

- (θ, τ) 相关不显著（−0.11）；θ 显著预测整体表现（R²=32.34%），τ 单独无效、与 θ 联合时小幅显著（ΔR²=1.09%）[A5, p.1064-1066, Tables 3-5]。
- 两任务联合 > 单任务（R² 33.43% vs 24.18%/23.78%，增量 9.25%/9.65% 均显著）[A5, p.1066, Table 5]。
- 复杂任务（任务 2）过程数据比结果信息更多（+6.31%）；简单任务（任务 1）没有（−0.19%）[A5, p.1066, Table 5]。

## 5.15 局限

**Paper-stated**：动作选择与时间子模型可能过度简化，易模型误设，不推荐高风险评分 [A5, p.1071]；要求先验指定任意历史下的动作有效性，限制复杂任务 [A5, p.1071]；EM 计算慢（未来可换算法）[A5, p.1071]；GOF 方法待发展 [A5, p.1070-1071]；无多特质扩展（论文指出可扩展为多维，需每步设计信息）[A5, p.1071]。

**Transfer limitations（迁移到英语阅读）**：
- 有效性标注障碍同 A1/A3/A4（且 CTDC 要求"任意历史下的所有动作"都标注，阅读中几乎不可行）；
- 任务级 β_k 太粗（A4 已证明状态级更优）；常数强度/指数等待时间与真实阅读节奏不符；
- τ（速度）在实证中信息有限（ΔR² 约 1%），需评估是否值得为它承担复杂度；
- 只测两个特质，不直接支持多阅读技能。

## 5.16 迁移到我们的英语阅读系统

**可以直接迁移**：
- **marked point process 视角**：把"阅读日志 = (事件类型, 时间戳)"看作带标记点过程——这是对阅读原始事件流最自然的概率化抽象之一。
- **指数等待时间 + 速度特质 τ** 的结构：可建模"选项消去节奏""答题速度"等，作为能力之外的**速度/投入度特质**。
- **EAP 个体打分机制（论文明确实现）**：固定参数后对新学生一步 EAP [A5, p.1061]。这是 A 组中唯一在论文中显式实现"标定→个体快速估计"路径的模型；**A1/A3/A4 结构上亦可改造（参数标定后对新学生做后验更新/MAP/EAP，论文未演示）**，见 §7 Q9。
- 右删失/任务缺失处理：适合学生中途退出/时间不够的真实场景。

**需要修改后迁移**：
- 原论文：任务级 β_k + 二元有效性 V。
- 我们：需把动作选择子模型升级为**状态级易度**（用 A4 的 β_ks），并把有效性 V 替换为**针对阅读动作的自定义价值函数**（对选项类动作=正确/错误；对 scroll/underline=从阅读理论导出的事件价值，需 B 组文献）。
- 时间子模型需从"常数强度"扩展为**允许状态/事件类型依赖的强度**（如读长段时强度低、作答时强度高），否则指数恒速假设会失真。
- τ 的语义需要重新定义：对阅读，"动作速度"与"阅读理解深度"可能负相关，二元正态+可分离结构需验证。

**不适合迁移**：
- 期望 CTDC 直接测"阅读技能掌握"——它测的是"选有效动作的倾向 + 速度"，不是技能；
- 对无"有效性"定义的行为（自由阅读）直接套 Eq. 1。

**该论文最适合解决的层**：`Focus / Engagement 类时间特质`（速度 τ 层面）、`Cognitive Inference`（能力 θ）、`Student Model`、`Validity / Evaluation`（预测验证模板 + 在线推断）。

**它解决不了什么**：行为→认知的构念有效性（作者自认 GOF/验证薄弱）；多维阅读技能（仅指扩展方向，未实现）；策略异质性；无有效性标注行为；有效性标注的自动化。

## 6.1 关键差异解释（比较矩阵补充）

1. **唯一真正的"能力测量模型"是三列**：A1/A3/A4/A5 都能从过程数据估计个体能力；A2 不能。区别在能力的"维度与结构"：A1 多维、A3 单维但带类别、A4 单维、A5 双特质（能力+速度）。
2. **唯一的时间模型是 A5**：其余全部只吃动作顺序。这是 A 组在时间维度上的最大落差，也意味着"scroll dwell / pointer dwell"这类我们关心的信息，A 组只有 A5 的框架可以承接，且需要改造。
3. **隐藏状态只有 A2**：其余模型的"状态"是专家定义的可观测任务状态。**注意语义陷阱**：A1/A3/A4/A5 里没有"潜在认知状态"这个东西；只有 A2 有"统计隐藏状态"，且其认知含义是事后贴的。这与我们架构中 `State Reconstruction → Focus State Estimation` 的层次**不对应**——A 组没有一篇真正做"raw → latent behavioral state → cognitive state"的连续推断。
4. **正误/有效性标注是 A1/A3/A4/A5 的共同前提**，A2 是唯一不需要"动作正确性"的模型（代价是不测能力）。**这决定了我们的取舍**：要能力估计就必须解决"阅读动作的正确性从哪来"；否则只能用 A2 这类模式发现。
5. **异构性处理只有 A3 内生**；A2 靠模型外分组；A1/A4/A5 假设同质。对我们的"同样能力、不同策略"需求，A3 是 A 组内的唯一内生选项。
6. **在线打分路径 A5 在论文中最明确**（MML/EM 标定 + EAP 估计个体），A1/A3/A4 论文未实现在线打分，但任务参数离线标定后，其模型结构同样支持对新学生的后验更新 / MAP / EAP（数学上可行，论文未演示）。**选型时应区分"论文明确实现"与"结构可改造"**：A5 属于前者且最成熟，A1/A3/A4 属于后者、可行但需要工程化。

# 7. 十个跨论文研究问题

## Q1. 哪种方法最真正实现了 process data → student ability？

**答案：A1、A4、A5（以及 A3 的类别扩展版）是真正的测量模型；A2 不是。**

依据：
- A4/A5/A1/A3 都在模型内部定义了学生级潜在能力变量，并把**整条过程序列的对数似然**写成能力与参数的函数：A4 `P(选择|θ,β)` [A4, p.260, Eq. 1]、A5 `P(选择,等待时间|θ,τ)` [A5, p.1061]、A1 `P(状态转移|θ向量,λ)` [A1, p.4, Eq. 2]、A3 `混合 P(选择|θ,c,β)` [A3, p.83, Eq. 1-2]。能力直接从过程数据（而非结果分数）估计。
- A2 没有任何能力参数，隐藏状态是唯一潜在结构，表现只是外部分组变量 [A2, p.5-6, §3.2]。它做的是 **process pattern 聚类/描述**，不是能力测量。

**最重要的限定**：这四篇的"能力"都通过**预先人工标注的正确性（I⁺ / Iss′ / V）**识别。所以最严格的说法是：它们实现了 **"过程 → 选对预先标注正确动作的倾向 → 能力"**，其中"正确"是研究者预先注入的。这既是它们比 A2 强的地方（真正可标定个体能力），也是它们的构造性局限（能力语义受标注质量限制）。**如果我们要声称"过程→阅读技能"，就必须提供同等强度的"阅读动作正确性/技能映射"标注，否则即便套用这些模型，估计出的也只是"与正确性相关的行为倾向"。**

## Q2. behavioral state / strategy / latent class / latent cognitive state / latent ability 在五篇中分别是什么关系？

| 概念 | 在哪篇、是什么、由谁定义 |
|---|---|
| behavioral state（行为状态） | A2：HMM 隐藏状态 = 一组动作倾向的聚簇（统计状态）；数据驱动产生，数量靠 AIC/BIC+文献 [A2, p.7-8]。A1/A3/A4/A5 的"状态"是**可观测任务状态**（专家定义），不是潜在行为状态。 |
| strategy（策略） | A3：潜在类别被事后解读为"策略型差异"（Class 1 能纠错 vs Class 2 不纠错）[A3, p.100-101]。A2：转移路径被事后解释为 Polya 步骤的组合 [A2, p.9, Table 1]。**两者都是研究者赋予的解释，不是模型内生参数**。A1/A4/A5：无策略概念。 |
| latent class（潜在类别） | 只有 A3：离散类别成员 c_i，类别差异体现在状态易度剖面与能力方差 [A3, p.82-83]。A2 的"正确/错误组"是观测分组，不是估计的类别。 |
| latent cognitive state（潜在认知状态） | 只有 A2 声称隐藏状态≈"认知反应状态"，但作者明确承认认知解释是事后理论贴标 [A2, p.2]。**没有任何一篇在模型内部证明隐藏状态/类别是认知状态**。 |
| latent ability（潜在能力） | A1（多维）、A3（单维，类别条件）、A4（单维）、A5（能力+速度）。全部是连续学生级特质，通过"正确动作选择"识别。A2 无。 |

**关系要点**：(a) A3 是 A4 的"异质性扩展"（A4 同质 → A3 加类别）；(b) A2 的隐藏状态与 A1/A4 的任务状态**不是同一层级**——前者是统计潜在层，后者是可观测系统层；(c) 五个概念中，只有 latent ability 在模型内被严格定义；behavioral/cognitive state 与 strategy 都是**事后标签**。

## Q3. 我们的 raw events（scroll/viewport/navigation/underline/elimination/answer/pointer）哪些模型能直接接？

**没有任何一个模型能直接接原始事件流。** 分两层看：

- **能直接接"语义化动作序列"的只有 A2**：PIAAC 的 MAIL_VIEWED/COMBOBOX 这类动作已经是语义抽象。我们的 `question_navigated / option_elimination_toggled / underline_created / answer_selected` 若能先规范成语义动作词汇，A2 的 HMM 可以**直接**处理（无需正确性标注）。
- **A1/A3/A4/A5 必须两级抽象**：先 `Raw Events → Micro Actions`（把 scroll/pointer 切成动作块），再 `Micro Actions → Higher-Level States`（把动作折叠进"阅读/作答进度状态"），并且**必须对每个状态转移给出正误/有效性标注**。这两步 A 组论文都没有提供自动化机制（A1 只说到"规则一旦建立可程序化提取" [A1, p.13]，A4 建议 HMM 辅助 [A4, p.271]）。
- **pointer / scroll / viewport 这类连续低层事件**：五篇全部不直接建模。A5 是唯一能把"时间戳"纳入的，但它的"事件"仍是语义动作，不是 pointer 采样。

**结论**：如果做 `Raw → Micro Action` 的中间层（D 组文献的关键），A2 的 HMM 是入口；如果再做 `Micro Action → Task State + 正误标注`，A1/A3/A4/A5 的能力模型才能接上。**我们架构里 `Action Segmentation` 是 A 组模型的前置必需品，A 组没有提供它。**

## Q4. 能否建立 `Raw Events → latent behavioral states → latent reading skills/abilities`？

**分两段看**：

- **前段 `events → latent behavioral states`**：A2 提供了统计模板（HMM 隐藏状态），但它要求输入已是语义动作 [A2, p.5-6]，且状态的认知语义未获验证。统计依据存在但不充分。
- **后段 `latent states → abilities`**：A 组**没有任何论文把"潜在行为状态"作为中介再接能力**。A1/A3/A4/A5 的能力都是从"可观测任务状态下的选择"直接连的，中间没有潜在行为状态层。唯一的"连接"是 A2 用正确/错误分组做**组间描述**，不是能力估计。

**因此：`Raw Events → latent behavioral states → latent reading skills/abilities` 这条完整链条在 A 组没有现成统计依据。** 缺什么：(a) 一个把 raw 阅读事件映射到行为状态（含状态数与语义）的模型层——需要 D 组（分割）与 B 组（阅读行为语义）文献；(b) 一个把行为状态连接到多阅读技能的正规测量模型——需要 E 组（认知诊断/Q-matrix）文献；A1 的 I⁺ 思路可作为"行为×技能"映射的形式模板，但 I⁺ 的标注对象必须从"任务转移"换成"阅读行为/进度事件"。**A 组的贡献是提供了"动作选择→能力"与"事件→隐藏状态"这两块的各自统计机制，连接这两块的工作 A 组未做。**

## Q5. 多维能力模型是否适合技能级（skill-level）建模？

**结构上适合，标注上非常苛刻。**

- A1 的 MSRM 就是为"多维技能"设计的：I⁺ 矩阵把每个状态转移映射到 D 个技能维度（+1/−1/0）[A1, p.4]。这正是认知诊断里 Q-matrix 的过程数据版。如果你愿意为每条"选项类动作"标注它测哪项技能（information locating / evidence integration / local inference / global inference / main idea / vocabulary-in-context / evaluation），A1 在**数学上**完全能输出每个学生在每项技能上的估计 + 技能间相关（Σ）。
- A5 在讨论中明确说可扩展为多维特质，"前提是每一步涉及哪些特质的设计信息可得" [A5, p.1071]——与 A1 的 I⁺ 同一条件。
- **额外条件**：(a) 每条被标技能的动作必须有明确"正确/错误"；(b) 技能×动作的映射要由阅读理论支撑（否则就是循环论证）；(c) 需要足够样本量与序列长度（A1 模拟 n≥500、A3 建议均长≥30 [A3, p.102]）；(d) 补偿/非补偿形式需按阅读理论选择 [A1, p.4]。**对阅读来说最大障碍仍是"正确性"**：information locating 可以通过"是否定位到关键句"近似，但"local inference"如何从行为上定义正误？这需要 B 组（阅读认知研究）提供行为指标。

## Q6. 同样能力、不同策略（Student A/B/C），哪种模型最适合？

**A3（Mix1P-SR）是 A 组内唯一内生方案。**

- A3 用潜在类别 + 类别专属状态易度刻画"不同的状态响应模式" [A3, p.82-83]。Student A（全文阅读→回题）、Student B（先看题→边读边答）、Student C（快速扫描→回读）会表现为不同的"在哪些状态下做什么动作"的剖面，A3 可以把它们分到不同类别。
- A2 只能在正确/错误组之间做描述性比较（模型外二分），且组内仍假设同质 [A2, p.5-7]。A1/A4/A5 明确同质假设。
- **但 A3 的局限要讲清楚**：类别同时携带能力分布差异（每类 σ²_g 不同），所以**"低能力"与"不同策略"在类别里是纠缠的**；A3 论文自己也承认各类别能力均值固定 0、参数不可跨类直接比较 [A3, p.103-104]。如果要严格分离"同能力不同策略"，需要 A3 + 把能力对齐到共同尺度的额外处理（论文建议 item anchoring/centering 等 [A3, p.104]）。
- 另一种工程路线：保留 A4/A5 的能力模型 + 用 A2 的 HMM 状态序列做**模型外聚类**来刻画策略（即策略不进入能力估计，而是事后分组）。代价是策略与能力的关系无法在同一概率模型内刻画。

## Q7. 五种模型在 new item / new task generalization 上的结构性限制

**共同的结构性限制：每个新任务都要重新注入专家知识（状态空间 + 正确性/有效性），模型本身不提供迁移机制。**

- **A1**：新任务需重新定义状态、可达集、I⁺ 矩阵；λ 重新估计。θ 的共享尺度（MVN(0,Σ)）在结构上允许跨任务比较（论文未明确论述多任务联合估计，此为结构推断），但"新任务的状态抽象"完全靠人 [A1, p.13-15]。
- **A2**：新 item 需重新定义动作词汇、重拟合 HMM、重选状态数；状态是 item-specific，**没有任何跨 item 参数共享** [A2, p.8, p.14]。
- **A3**：新任务需定义状态+正误并估计新 β_ksg；共享 θ、π 使结构可扩展（加入新任务=加参数组）[A3, p.83, Eq. 3]。
- **A4**：同上，新任务加状态易度参数 β_ks [A4, p.262]。
- **A5**：新任务需定义状态+有效性（**要求最严：任意事件历史下的所有动作**）并估计 β_k、γ_k [A5, p.1057, p.1071]。

**对我们的阅读场景**：新 passage 的核心障碍不是估计（共享 θ 的扩展机制都在），而是**"每道题的选项有对错、但阅读行为没有对错"**这一事实 + 状态抽象需要逐 passage 人工定义。A1/A3/A4/A5 的"新题扩展"都建立在"新题的动作正确性已经标注好"的假设上。**这意味着：如果系统要处理从未见过的新 passage，必须先有一个能把任意 passage 的动作自动转成"带正确性标注的状态"的层——A 组没有，需要 B/D/E 组文献支撑（行为标注规则 + 分割自动化 + Q-matrix 生成）。**

## Q8. 时间信息值得保留到什么程度？

- **sequence only**（A1/A3/A4）：信息最弱，但也是唯一在 A 组里被验证的；能力-结果相关可达 0.77–0.79、R²≈38% [A4, p.269-270]。
- **sequence + dwell**：A 组无模型直接支持（A5 只有 inter-event 等待，无状态驻留异质性）。
- **discrete transition**（A1/A3/A4 的状态转移、A2 的 HMM 转移）：本质仍是无时间。
- **continuous-time event modeling**（A5）：真正利用时间戳。

**A5 实际增加了什么**：(1) 一个速度特质 τ，估计表明单独几乎无解释力（R²=0.04%，p=0.69），与 θ 联合时贡献 ΔR²=1.09%（p=0.01）[A5, p.1065-1066, Tables 4-5]——**信息增量小而代价大（指数恒速假设 + 误设风险）**；(2) 右删失/缺失处理（对真实场景有价值）[A5, p.1070]。

**建议**：时间信息**值得保留，但优先保留"粗粒度时间特征"**（如题级 dwell、选项消去节奏、段落驻留），而不是完整连续时间模型。理由：(a) A5 的实证显示纯速度信息对能力预测增益约 1%；(b) 常数强度假设对阅读明显失真（阅读的驻留高度异质）；(c) 若未来要建模"聚焦状态/投入度"，连续时间框架（A5 的 marked point process 视角）是正确基底，但子模型要重设计。**权衡结论：sequence + 粗粒度时间特征（作为附加协变量/特质）是性价比最高；完整 CTDC 的常数强度版本不推荐直接采用。**

## Q9. 哪些适合 offline population modeling，哪些可能适合 online inference？

- **offline population modeling**：全部五篇。A1/A3/A4（MCMC 批处理，需 n≥500–3000、长序列）适合事后离线标定；A5（MML/EM）也适合。
- **online student-state inference**：
  - **A5 在论文中明确实现**：MML/EM 标定任务参数 (β,γ,Σ)，个体 (θ,τ) 用 EAP 一步估计 [A5, p.1061]——A 组内唯一论文内建"参数离线标定 → 个体快速估计"打分路径的模型。
  - **A1/A3/A4 结构上可改造**：任务参数（λ/β/π、σ²）离线标定后，新学生的 θ 同样可通过固定参数下的后验更新 / MAP / EAP 近似估计（数学结构可行，论文未演示）。**"论文未实现 online scoring"≠"模型结构做不到"**。
  - **A2**：原理上可用前向算法在线滤波 P(状态_t|历史)，但论文未讨论、且只给状态不给能力。
  - 数据需求仍是选型要点：A3（均长≥30、n≥1000）对在线/小样本最不友好；A1/A4 对样本与序列长度的需求居中。

**工程建议**：先离线用 A4/A5 风格模型标定任务参数，线上用固定参数对新学生做 EAP/滤波式推断（A5 的 EAP 机制最直接；A1/A3/A4 结构上同样可行，见上）。A 组没有任何真正的在线实验，这是"未报告/需验证"部分。

## Q10. 只看这 5 篇，它们共同无法解决的最大问题是什么？

按重要性排序：

1. **语义理解缺位**：所有模型把动作当作抽象符号，不读内容。阅读里"读到了哪句话""是否理解上下文"这类语义状态完全不在 A 组任何模型的输入里。`scroll 落到 P2 ≠ 正在读 P2` 这类推断链，A 组模型既不能确认也不能纠正。
2. **行为→认知的 construct validity 未建立**：A2 明说认知解释是事后贴标 [A2, p.2]；A1/A3/A4/A5 的"能力"只等价于"选对预标注动作的倾向"。没有任何论文证明 latent state/class/ability 真的对应某个心理构念。**把 prediction accuracy（R²=0.38 等）当构念有效性是错误的。**
3. **focus / attention 不确定性**：五篇都不区分"视口显示/指针停留/实际注意"。对我们的 `Focus State Estimation` 层没有任何直接支持。
4. **新任务泛化**：全部依赖人工状态+正确性标注；没有自动把新 passage 转成带标注状态空间的机制（见 Q7）。
5. **行为策略与能力混淆**：A1/A3/A4/A5 的能力识别假设"选正确动作"代表能力，但不同策略（如谨慎回读 vs 一次到位）会污染能力估计；A3 的类别与能力纠缠。**模型无法回答"这个学生是能力低，还是策略不同？"**

# 8. A 组确立了什么

## 强证据

1. **"动作选择 + 连续潜在能力"的测量机制是可工作的**：A4/A5/A1/A3 的模拟都显示参数与能力恢复良好（A4：状态参数 RMSE<0.1、能力 bias±0.01 [A4, p.264]；A1：λ RMSE 0.04–0.10、Σ 相关恢复 [A1, p.8, Table 2]；A5：固定参数恢复合理 [A5, p.1068]）。这是对"过程数据能标定个体能力"的可靠统计证据。
2. **从过程估计的能力对任务结果/整体表现有中等偏强的预测力**：A4 能力-结果相关 0.769/0.785、R²=0.384 [A4, p.269-270, Tables 7-8]；A5 能力 R²=32.34% [A5, p.1065, Table 5]；A1 技能-结果相关 0.393–0.523 [A1, p.14]。**但注意这仍是"预测/效标关联"，不是构念有效性。**
3. **状态级难度参数有意义**：A4 实证显示同一任务内各状态易度差异显著、最优路径状态更"容易选对" [A4, p.268-269, Tables 5-6]，五个指标一致支持状态级优于任务级（SR>DC）[A4, p.268, Table 4]。这支持"过程分步诊断"的可行性。
4. **存在可检测的行为异质性（类别）**：A3 实证在 27,616 人中发现两个行为类别，类别×结果高度相关（Class 1 两任务全对 54.53%，Class 2 几乎为 0）[A3, p.101, Table 4]。
5. **连续时间框架可承载日志数据**：A5 把日志形式化为 marked point process 并成功估计（含时间）[A5, p.1055-1061]。

## 部分证据

1. **多维能力（多技能）建模在数学上可行**：A1 的 MSRM 结构支持，但只有模拟+两个单任务实证，且技能映射全部人工 [A1, p.4, p.13-14]。迁移到阅读技能需要外部提供"行为×技能"映射依据。
2. **时间信息有微弱增量**：A5 的速度特质 ΔR²≈1.09%（p=0.01）[A5, p.1065-1066, Tables 4-5]。方向正确但幅度小、且基于简化假设，需要更多证据判断值不值得。
3. **"过程数据比结果数据信息更多"取决于任务复杂度**：A5 任务 2 过程>结果（+6.31%），任务 1 无增量（−0.19%）[A5, p.1066, Table 5]。对复杂阅读任务可能成立，需要阅读数据验证。
4. **类别能近似捕捉策略差异**：A3 的类别行为描述（纠错 vs 不纠错）合理 [A3, p.100-101]，但类别与能力纠缠、无独立策略验证，只能算"部分证据"。
5. **隐藏状态可稳定提取并支持组间差异描述**：A2 的 HMM 在样本较小的组（62 人）也能跑通 [A2, p.5]，但其有效性只有描述性支持。

## 未支持 / 仍未决（留给 B/C/D/E 组）

1. **cursor/pointer 是否能代表 attention / focus**——A 组完全未涉及。
2. **如何把 raw mouse/scroll/viewport 自动切成 action blocks**——A 组依赖人工编码或 OECD 预编码。
3. **英语阅读中哪些行为代表 evidence search / integration**——A 组没有阅读语义。
4. **latent state / latent class 是否真的代表某种认知状态**——A 组没有任何构念有效性证据（A2 自己承认是事后解释）。
5. **"选正确动作"的能力与"阅读技能"是否是同一个构念**——未验证，且这是迁移的核心风险。
6. **新 passage 的自动状态化与正确性标注**——无机制。
7. **策略与能力在同一模型内的分离**——A3 部分相关但未解决。
8. **时间信息（dwell/scroll 节奏）在阅读中的真实价值**——只有 A5 的 1% 证据，且非阅读场景。

# 9. 需要 B–E 组提供什么

以下需求不是论文搜索关键词，而是 A 组暴露出的技术缺口：

## B（英语/数字阅读论文）具体需要验证什么

1. **阅读过程理论框架**：A2 用 Polya 四步解释状态；我们的阅读需要一个同等地位的过程框架（如 search → extract → integrate → evaluate/verify）。B 组要提供"被阅读研究接受的、可映射到可观测行为的过程阶段"。
2. **行为→技能的可操作指标**：A1 的 I⁺ 需要"哪个动作对哪项阅读技能是正确/错误的"。B 组要给出：evidence search 的行为指标（如回读、定位、关键句驻留）、inference 的行为指标、main idea 的行为指标等，且要有实证支持（不是专家拍脑袋）。
3. **聚焦/投入度的行为代理**：A 组无法处理"视口≠注意"。B 组要提供阅读场景下 dwell / scroll / 回看与阅读理解的相关证据，用于支撑我们的 Focus Estimation 层。
4. **复杂阅读任务的"过程信息增量"验证**：A5 发现任务越复杂过程越有增量 [A5, p.1066]。B 组要评估英语阅读题（特别是推理题）是否足够复杂，值得做过程建模。

## C（Mouse / Cursor 文献）具体需要验证什么

1. **cursor/pointer 能否代理注意**：A 组完全不涉及。C 组要提供 mouse-tracking / cursor-position 与注视/注意一致性的实证（相关多少、什么条件下失效），以及 hover/悬停是否携带语义信息。
2. **scroll 行为的认知解释**：scroll 速度、方向、回滚与阅读理解/重读的关系；哪些 scroll 特征可作为"证据检索"的指标（供 B 组行为指标落地）。
3. **pointer 事件的去噪**：采样频率、抖动、噪声的处理标准，供 Action Segmentation 层使用。

## D（Action Segmentation 文献）具体需要验证什么

1. **raw event → micro action 的分割方法**：A 组没有这一层。D 组要给出从 scroll/pointer/viewport 流中切出"读段落 / 找信息 / 作答 / 消去选项"等动作块的方法与验证（边界怎么定、粒度怎么选）。
2. **micro action → task state 的自动化**：A1/A4 建议用 HMM/数据驱动辅助定义状态 [A1, p.15; A4, p.271]。D 组要给出在阅读场景下自动构造"信息状态"（如'已看关键句'）的方案与稳定性证据。
3. **动作词汇的构建与裁剪**：A2 直接吃 OECD 语义动作；我们的动作词汇需要自己建。D 组要给出阅读动作本体/词汇设计（含低频动作处理、同义动作合并）。

## E（Cognitive Diagnosis / Validity）文献具体需要验证什么

1. **Q-matrix 式"行为×阅读技能"映射的效度**：A1 的 I⁺ 是 Q-matrix 的过程版。E 组要给出阅读技能 Q-matrix 的建立与验证方法（专家 vs 数据驱动；识别性检验）。
2. **latent state/class 构念有效性的验证框架**：A 组全部缺少构念证据。E 组要给出：如何用外部测量（阅读测验分数、教师评定、眼动）验证我们估计的潜在状态/能力确实是"阅读认知"而非"界面操作熟练度"。
3. **能力与策略分离**：A3 的类别与能力纠缠 [A3, p.103-104]。E 组要提供统计方法（如混合 IRT 中的 scale anchoring/centering、能力-类别联合建模）或理论框架，使系统能区分"低技能"与"不同策略"。
4. **新任务泛化的效度策略**：如何在少量新 passage 上验证"状态定义规则 + 技能映射"的稳定性（跨 passage 泛化的测量等价性）。
