# Provenance

- [SOURCE_POLICY.md](SOURCE_POLICY.md)：恢复来源与科学事实的双轴权威顺序。
- [RECOVERY_LOG.md](RECOVERY_LOG.md)：本轮恢复做了什么、没有做什么。
- [CONFLICT_REGISTER.md](CONFLICT_REGISTER.md)：历史矛盾、裁决和开放项。
- [CLAIM_LEDGER.md](CLAIM_LEDGER.md)：关键 canonical claim 到原始位置的映射。
- [ASSET_MAP.md](ASSET_MAP.md)：本地资产的用途、状态和公开边界。
- [PAPER_REPORT_CROSSWALK.md](PAPER_REPORT_CROSSWALK.md)：论文 ID、旧 basename 与报告映射。
- [LEGACY_REPORT_PROVENANCE.md](LEGACY_REPORT_PROVENANCE.md)：C/D/E 历史任务书的 raw-chat 定位与不可得反馈文件的限制。
- [PUBLICATION_READINESS.md](PUBLICATION_READINESS.md)：公开 GitHub 前的隐私、版权、密钥与暂存区边界审计。
- `RAW_SOURCE_MANIFEST.sha256`：冻结恢复材料的文件校验值。

这些文件用于审计和冲突回溯；日常研究入口仍是 `reports/project_state/` 与 `reports/synthesis/`。
