## What is not recoverable as an independent file

The D and E reports refer to a historical desktop file named `反馈.md`. No independent copy of that file exists in the recovered workspace or in the three exported transcripts. The original file must therefore be treated as `UNAVAILABLE`, not silently reconstructed. Its machine-local absolute path is intentionally not retained in the public project record.

The surviving evidence is the detailed revision record embedded near the top of each final report. Those records identify every applied correction and its destination section. They prove what the final report claims was changed, but they are not an independent copy of the reviewer's original wording.

## Canonical interpretation

- The final report files are durable literature assets, subject to local-PDF re-verification.
- The raw Chat 2 task instructions establish generation intent and scope, not scientific truth.
- The embedded revision records establish the final report's own change history.
- A missing historical feedback file is a provenance limitation; it does not invalidate a claim that can be independently checked against a local PDF.
- No future report may cite an external personal desktop path as a current dependency.
