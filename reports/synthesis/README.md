# 研究综合

本目录包含从历史研究恢复、经冲突裁决后供日常研究使用的 canonical 综合。

- [SYSTEM_DESIGN.md](SYSTEM_DESIGN.md)：baseline 系统边界、UI、数据与分层架构。
- [OBSERVABILITY_TARGETS.md](OBSERVABILITY_TARGETS.md)：目标、证据、可识别性与未知类别。
- [MEASUREMENT_VALIDATION_FRAMEWORK.md](MEASUREMENT_VALIDATION_FRAMEWORK.md)：Phase 2A 的题目无关测量与验证规范。
- [DEVELOPMENT_BENCHMARK_SPEC.md](DEVELOPMENT_BENCHMARK_SPEC.md)：Phase 3 的开发数据与 benchmark 草案；不是已完成实验。
- [LITERATURE_SYNTHESIS.md](LITERATURE_SYNTHESIS.md)：A–E/UIB 文献资产的系统角色与证据边界。
- [ITEM_AND_DATA_SOURCE_STATUS.md](ITEM_AND_DATA_SOURCE_STATUS.md)：Phase 0 的真实完成度与待取得资产。

所有判断都必须同时读取其状态标签。`DESIGN CLOSED` 只表示题目无关的设计问题已充分讨论，不表示代码、实验或科学效度已完成。
