This repository uses multiple licenses because code, original research prose, metadata, and third-party sources have different rights.

| Material | License / status |
| --- | --- |
| Source code and executable scripts authored for this project | [Apache License 2.0](../LICENSE) |
| Original project reports, protocols, diagrams and documentation | [CC BY 4.0](CC-BY-4.0.txt) |
| Original bibliographic catalog fields and machine-generated checksums | [CC0 1.0](CC0-1.0.txt), to the extent the project has rights to dedicate them |
| Third-party papers, standards, excerpts, datasets and linked resources | Their respective owners' terms; **not** relicensed by this repository |
| `webchat_raw_materials/` | Private recovery evidence; excluded from public Git and not licensed for redistribution |
| Human-participant data and sensitive research records | Restricted; never covered by the public repository licenses |

The presence of a local PDF or a bibliographic record does not establish redistribution permission. Each third-party file requires its own recorded rights evidence before public release.
