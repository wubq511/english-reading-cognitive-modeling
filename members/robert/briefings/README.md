# briefings — 成员个人展示材料

面向团队成员与导师的结果说明页（HTML），由成员个人维护。

规则：

- 这里的内容**只呈现、不拥有任何事实**。每页注明 canonical owner（如 `reports/decisions/` 下的决议记录）；结论变更只改 owner，briefing 随之重生成。
- 每个主题一个子目录；页面做成**单文件自包含 HTML**（图片 base64 内联），保证单个文件发出去即可直接查看。
- 读者是研究成员与导师，正文用中文；状态枚举值保持英文。
- 本目录内容进 git（便于导师/成员查看），但它不是 canonical 研究资产，不作为任何结论的引用源。
