# Use rights-aware paper manifests instead of blanket PDF Git storage

Public Git tracks bibliographic metadata, exact hashes, acquisition instructions and rights status; third-party PDFs remain in each collaborator's local cache unless a specific version has verified redistribution rights. A fail-closed paper preflight automatically downloads only catalog-approved legal sources and otherwise gives the user an exact manual acquisition request. This preserves full-text availability for research Agents without treating Git LFS or Releases as a substitute for copyright permission.
