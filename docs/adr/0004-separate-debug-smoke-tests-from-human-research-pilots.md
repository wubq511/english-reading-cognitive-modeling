# Separate debug-only smoke tests from human research pilots

External-person smoke tests may only find interface or engineering defects and produce `NONRESEARCH_DEBUG_ONLY` issue records; they retain no person-level performance data and can never be converted into research evidence. Any systematic logs, performance, interview, recall, cognitive label or publishable analysis is an H2 research pilot requiring prior institutional review and informed consent. The separation is fixed at collection time because retrospective approval or consent cannot repair an unapproved research dataset.
