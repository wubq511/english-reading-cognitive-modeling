# Use raw transcripts for recovery, canonical reports for daily research

The current user's decisions and complete chat transcripts outrank handoffs and the migration package for project-state recovery; scientific claims instead follow papers, standards and reproducible experiments. Raw materials remain a checksummed, locally frozen evidence library excluded from public Git, while daily work uses canonical `reports/` assets. This preserves dispute-level traceability without repeatedly exposing future Agents to obsolete or contradictory discussion.
