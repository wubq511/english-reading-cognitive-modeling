# Agent workflow documentation

本目录只维护 Agent 协作工作流，不维护动态研究状态或科学结论。

- [`research-workflow.md`](research-workflow.md)：Wayfinder → Spec → Tickets → Implement 的唯一状态机、artifact ownership 与 transition gate。
- [`issue-tracker.md`](issue-tracker.md)：GitHub Issue、labels、sub-issues、dependencies、claim 和 publication 操作契约。
- [`domain.md`](domain.md)：项目单一 domain context 与术语/ADR 读取规则。
- [`SKILL_EVALUATION.md`](SKILL_EVALUATION.md)：Codex/Claude 行为 eval、结构检查与跨平台待验项。
- [`WORKFLOW_COMPLETION_AUDIT.md`](WORKFLOW_COMPLETION_AUDIT.md)：对用户目标逐项核验的完成证据与 publication boundary。

动态完成度仍以 [`../../reports/project_state/CURRENT_STATE.md`](../../reports/project_state/CURRENT_STATE.md) 为准；科学证据和 owner 规则仍以 [`../../reports/provenance/SOURCE_POLICY.md`](../../reports/provenance/SOURCE_POLICY.md) 为准。
